# ESP32手机管理箱 - 开发总结

## 一、项目概述

本项目实现了一个基于ESP32的双箱手机管理系统，支持A箱（班主任远程控制）和B箱（学生刷卡验证）的智能管理。

## 二、核心功能模块

### 1. RFID读卡模块
- **模块型号**：DX-NF01（国产13.56MHz串口模块）
- **通信协议**：AT指令协议（默认波特率9600）
- **读卡逻辑**：每500ms发送 `AT+UID` 查询，解析十六进制UID
- **防重复**：同一张卡2秒内只识别一次

### 2. 继电器控制模块
- **双继电器独立控制**：A箱(GPIO4)、B箱(GPIO16)
- **自动关锁**：开锁后3秒自动关闭
- **状态反馈**：开锁时发送"opened"，关锁时发送"closed"

### 3. OLED显示模块
- **屏幕规格**：128x64 SSD1306 I2C接口
- **显示场景**：
  - 正常运行："手机管理箱 / A箱:远程等待 / B箱:请刷卡 / 就绪"
  - A箱开锁："箱门已开 / 请班主任操作 / 3秒后自动锁闭"
  - B箱开锁："箱门已开 / 请学生操作 / 3秒后自动锁闭"
  - 积分不足："B箱开锁失败 / 积分不足: X / 需≥60分"
  - 卡号未注册："B箱开锁失败 / 卡号未注册 / 请联系班主任"

### 4. LED与蜂鸣器模块
- **双色LED**：红灯(GPIO25)、绿灯(GPIO26)
- **蜂鸣器**：GPIO27，支持多频次响铃

### 5. MQTT通信模块
- **服务器**：阿里云EMQX（nc5233fc.ala.cn-hangzhou.emqxsl.cn:8883）
- **SSL加密**：支持TLS连接
- **预置配置**：用户名`phoneboxtest`、密码`123456`

#### MQTT主题定义
| 主题 | 方向 | 用途 |
|------|------|------|
| `phonebox/unlock/A` | Server→ESP | A箱远程开锁指令 |
| `phonebox/unlock/B` | Server→ESP | B箱开锁指令（含验证结果） |
| `phonebox/query` | ESP→Server | B箱刷卡查询 |
| `phonebox/status` | ESP→Server | 状态上报（opened/closed/error） |
| `phonebox/log` | ESP→Server | 操作日志 |

### 6. 网页配网模块
- **Captive Portal**：自动弹窗配网
- **配网触发**：首次上电自动进入，或长按GPIO15按键3秒
- **AP热点**：SSID `PhoneBox-Config`，密码 `12345678`

### 7. 状态机架构
```
STATE_IDLE → STATE_UNLOCKING_A/B → STATE_IDLE
          ↘ STATE_ERROR_B → STATE_IDLE
          ↘ STATE_SHOWING_CARD → STATE_IDLE
```

## 三、硬件接线

| 外设 | ESP32引脚 | 说明 |
|------|-----------|------|
| RFID TX | GPIO17 (UART2_RX) | 串口接收 |
| RFID RX | GPIO18 (UART2_TX) | 串口发送 |
| 继电器A | GPIO4 | 高电平触发 |
| 继电器B | GPIO16 | 高电平触发 |
| OLED SDA | GPIO21 | I2C |
| OLED SCL | GPIO22 | I2C |
| 红LED | GPIO25 | 低电平亮 |
| 绿LED | GPIO26 | 低电平亮 |
| 蜂鸣器 | GPIO27 | 高电平响 |
| 门开关A | GPIO32 | 上拉输入（保留接口） |
| 门开关B | GPIO33 | 上拉输入（保留接口） |
| 配置按键 | GPIO15 | 上拉输入 |

## 四、操作流程

### A箱远程开锁
1. 服务器发送消息到 `phonebox/unlock/A`
2. ESP32接收指令 → 触发开锁
3. 发送状态 "opened" + 日志
4. 3秒后自动关锁 → 发送状态 "closed"

### B箱刷卡开锁
1. 学生刷卡 → RFID模块返回UID
2. ESP32发送查询到 `phonebox/query`
3. 服务器验证积分并返回结果
4. 成功：触发开锁；失败：显示错误信息并发送日志

## 六、技术亮点

1. **非阻塞状态机**：无delay()阻塞，响应更及时
2. **自动配网**：首次上电自动进入AP模式
3. **Captive Portal**：手机连接后自动弹窗配置页面
4. **状态反馈**：锁状态实时上报，失败场景有详细日志
5. **预置配置**：阿里云MQTT信息预置，开箱即用

## 七、配网说明

1. **自动进入配网模式**：首次上电或WiFi未配置时自动进入
2. **手动进入配网模式**：长按GPIO15按键3秒
3. **连接热点**：手机连接 `PhoneBox-Config`（密码：`12345678`）
4. **配置页面**：浏览器访问 `192.168.4.1`
5. **保存配置**：点击"保存配置"后设备重启并连接WiFi

## 八、测试工具

配套的网页MQTT测试工具（`mqtt-test-tool/`）：
- 支持连接阿里云MQTT（端口8084 WebSocket/SSL）
- 提供A箱开锁、B箱成功/失败测试按钮
- 实时显示设备状态和消息日志
