## ⚙️ 系统级依赖

### 必需的依赖（需预先安装）

#### 1. Python 3.10+
- **安装方式**: 
  - Windows: 从 [python.org](https://www.python.org/downloads/) 下载安装
  - 安装时**必须勾选** "Add Python to PATH"
- **检查命令**: `py --version`
- **一键部署会检查**: ✅ 是

#### 2. Node.js 16+
- **安装方式**: 
  - Windows: 从 [nodejs.org](https://nodejs.org/) 下载安装
  - 安装时**必须勾选** "Add to PATH"
- **检查命令**: `node --version`
- **一键部署会检查**: ✅ 是

#### 3. npm (随Node.js安装)
- **检查命令**: `npm --version`
- **一键部署会检查**: ✅ 是

### 可选的依赖

#### 1. Redis服务器
- **状态**: 可选（不是必需）
- **用途**: 缓存服务，提升性能
- **安装方式**: 
  - Windows: 从 [redis.io](https://redis.io/download) 下载或使用Docker
  - 或使用Memurai（Windows版Redis）
- **默认配置**: 
  - 主机: localhost
  - 端口: 6379
- **降级策略**: 
  - ✅ 如果Redis未安装或连接失败，系统会自动使用内存缓存
  - ✅ 不影响系统正常运行
  - ✅ 仅影响缓存性能，不影响功能
- **一键部署会检查**: ❌ 否（因为可选）

#### 2. SQLite
- **状态**: 内置（Python自带）
- **用途**: 默认数据库
- **安装方式**: 无需安装，Python内置
- **数据库文件**: `backend/instance/score_management.db`
- **一键部署会创建**: ✅ 是

## ⚠️ 重要说明

### Redis相关说明

1. **Redis客户端库会自动安装**
   - `redis>=4.0` Python包会自动安装
   - 这是Redis的Python客户端库

2. **Redis服务器是可选的**
   - 不需要预先安装Redis服务器
   - 系统可以在没有Redis服务器的情况下正常运行
   - 如果Redis服务器未运行，系统会自动降级使用内存缓存

3. **Redis服务器安装（可选）**
   - 如果需要Redis服务器，可以单独安装
   - Windows推荐使用Memurai或Docker运行Redis
   - 安装后修改 `.env` 文件中的Redis配置

### 数据库相关说明

1. **SQLite是默认数据库**
   - Python内置，无需安装
   - 数据库文件自动创建
   - 适合开发和中小型应用

2. **可切换到其他数据库**
   - PostgreSQL
   - MySQL
   - 需要安装对应的Python驱动
