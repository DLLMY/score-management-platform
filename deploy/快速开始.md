# 一键部署快速指南

## 🚀 5分钟快速部署

### 方法1：使用启动器（推荐）

1. **双击运行** `启动器.bat`
2. **选择** `[1] 一键部署`
3. **等待完成** 自动完成所有步骤
4. **访问系统** http://localhost:3000

### 方法2：直接运行一键部署

```bash
# 批处理版本
.\一键部署.bat

# 或Python版本（更好体验）
python .\one_click_deploy.py
```

## 📋 一键部署包含的步骤

```
✅ 步骤1: 检查系统环境 (Python 3.11, Node.js, npm)
✅ 步骤2: 安装后端依赖 (Flask, SQLAlchemy等)
✅ 步骤3: 安装前端依赖 (React, Tailwind等)
✅ 步骤4: 创建配置文件 (.env，基于 backend/.env.example)
✅ 步骤5: 初始化数据库 (SQLite)
✅ 步骤6: 创建核心索引 (create_indexes.py --create) + 校验 (verify_indexes.py)
✅ 步骤7: 初始化默认管理员 (密码取 ADMIN_INIT_PASSWORD，未设置则随机生成)
✅ 步骤8: 清理端口占用 (3000, 5000, 4040)
✅ 步骤9: 启动后端服务 (端口5000)
✅ 步骤10: 启动前端服务 (端口3000)
```

> 💡 核心索引为幂等创建（已存在跳过），后端启动时 `app/db_init.py` 也会自动自举，部署脚本的索引步骤是双保险。

## ⏱️ 预计时间

- **首次部署**: 5-10分钟（取决于网络速度）
- **后续启动**: 30秒-1分钟

## 🎯 部署成功后

### 访问地址
- 📱 **前端应用**: http://localhost:3000
- 🔗 **后端API**: http://localhost:5000
- 📚 **API文档**: http://localhost:5000/apidocs

### 登录信息

- 👤 **用户名**: admin
- 🔑 **密码**: 由 `ADMIN_INIT_PASSWORD` 环境变量决定
  - 设置了该变量 → 使用你设置的密码
  - 未设置 → **随机生成**，打印在**后端首次启动日志**（`⚠️ 临时密码: xxxx`），登录后请尽快修改
  - 不再固定为 `123456`

## 🔧 常见问题

### Q1: 提示"Python未安装"
**解决方案**:
1. 下载安装 Python 3.11（含 torch 依赖）
2. 安装时勾选 "Add Python to PATH"
3. 重启命令行窗口
4. 确认 `python --version` 输出为 3.11.x（不要依赖 `py` 启动器，它可能解析到 3.13 缺依赖）

### Q2: 提示"Node.js未安装"
**解决方案**:
1. 下载安装 Node.js 18+
2. 安装时勾选 "Add to PATH"
3. 重启命令行窗口

### Q3: 端口被占用
**解决方案**:
```bash
# 运行停止脚本
.\stop_all.bat

# 或手动清理
netstat -ano | findstr :5000
taskkill /F /PID <进程ID>
```

### Q4: 依赖安装失败
**解决方案**:
```bash
# 后端依赖
cd ..\backend
pip install -r requirements.txt

# 前端依赖
cd ..\frontend
npm cache clean --force
npm install
```

### Q5: 服务启动失败
**解决方案**:
1. 检查后端窗口和前端窗口的错误信息
2. 确认端口未被占用
3. 确认依赖已正确安装
