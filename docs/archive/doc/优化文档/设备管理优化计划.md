# 设备管理模块优化计划

## 文档概述

本文档记录了设备管理模块（设备管理、积分盒子、设备分组、固件管理、远程唤醒）的专项优化计划，包含优化项清单、优先级排序、实施步骤、验证标准及进度追踪表格。

---

## 一、优化概览

| 优化阶段 | 预计耗时 | 核心目标 | 涉及模块 |
|----------|----------|----------|----------|
| 阶段一：核心优化 | 1天 | 修复严重问题（N+1查询、安全漏洞、功能错误） | 设备管理、积分盒子、WOL |
| 阶段二：功能增强 | 1天 | 添加分页、搜索筛选功能 | 设备管理、固件管理 |
| 阶段三：性能优化 | 0.5天 | 数据库索引、缓存机制 | 全模块 |
| 阶段四：安全增强 | 0.5天 | 权限控制、设备认证 | 积分盒子、WOL、固件 |

## 三、阶段一：核心优化（1天）

### 3.1 D01: 告警列表设备名称预加载

**目标**：解决告警列表中每条记录都查询设备名称的N+1查询问题

**实施步骤**：
1. 获取所有告警记录
2. 提取所有设备ID，批量查询设备
3. 使用字典映射设备名称

**文件修改**：
- `backend/api/devices/devices_routes.py` (DeviceAlerts.get)

**验证标准**：
- [ ] 告警列表查询只执行2次数据库查询（告警+设备）
- [ ] 设备名称显示正确

### 3.2 D02: 设备列表分页支持

**目标**：为设备列表接口添加分页参数

**实施步骤**：
1. 修改DeviceList.get方法支持page、per_page参数
2. 修改get_devices_for_admin返回分页对象
3. 返回total、pages字段

**文件修改**：
- `backend/api/devices/devices_routes.py` (DeviceList.get)

**验证标准**：
- [ ] 支持page、per_page参数
- [ ] 返回total、pages字段

### 3.3 B01: box验证接口权限控制

**目标**：为积分盒子验证接口添加权限控制

**实施步骤**：
1. 导入requires_permission装饰器
2. 在BoxVerify.post方法添加权限装饰器

**文件修改**：
- `backend/api/devices/box_routes.py`

**验证标准**：
- [ ] 未登录用户无法访问验证接口
- [ ] 无权限用户返回403错误

### 3.4 W01: 修复DeviceStatus ping检查

**目标**：修复ping检查始终ping本地的问题，实际检查目标设备

**实施步骤**：
1. 通过ARP表获取MAC对应的IP地址
2. 使用获取的IP地址执行ping测试

**文件修改**：
- `backend/api/devices/wol_routes.py` (DeviceStatus.get)

**验证标准**：
- [ ] 能正确检测设备在线状态
- [ ] 返回真实的设备在线状态
