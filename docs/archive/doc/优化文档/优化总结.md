## 🚀 部署说明

### 1. 安装测试依赖

```bash
cd backend
pip install -r requirements.txt
```

### 2. 运行测试

```bash
# 运行所有测试
pytest tests/

# 运行特定测试
pytest tests/test_users.py

# 生成覆盖率报告
pytest tests/ --cov=. --cov-report=html
```

### 3. 启动应用

```bash
cd backend
python app.py
```

### 4. 验证配置

```bash
cd backend
python validate_config.py
```
