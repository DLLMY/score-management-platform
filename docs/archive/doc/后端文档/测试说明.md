# 后端测试指南

## 概述

本项目使用 pytest 框架进行单元测试和集成测试。测试覆盖了核心业务逻辑、API接口、安全性等方面。

## 测试结构

```
tests/
├── __init__.py           # 测试包初始化
├── conftest.py           # pytest配置和夹具
├── test_users.py         # 用户管理测试
├── test_rules.py         # 积分规则测试
├── test_devices.py       # 设备管理测试
├── test_unlock_validator.py  # 开锁验证测试
├── test_auth.py          # 认证授权测试
└── test_security.py      # 安全测试
```

## 安装测试依赖

所有测试依赖已包含在 `requirements.txt` 中：

```bash
pip install pytest pytest-cov
```

## 运行测试

### 运行所有测试

```bash
cd backend
pytest tests/
```

### 运行特定测试文件

```bash
# 运行用户管理测试
pytest tests/test_users.py

# 运行安全性测试
pytest tests/test_security.py

# 运行开锁验证器测试
pytest tests/test_unlock_validator.py
```

### 使用测试运行脚本

```bash
# 交互式选择测试类型
python run_tests.py

# 直接指定测试类型
python run_tests.py unit
python run_tests.py security
```

### 运行测试并生成覆盖率报告

```bash
pytest tests/ --cov=. --cov-report=html
```

生成HTML覆盖率报告在 `htmlcov/` 目录。

## 测试类型

### 单元测试 (Unit Tests)

测试单个函数或方法的独立行为。

```bash
pytest tests/ -m "not integration"
```

### 集成测试 (Integration Tests)

测试多个组件之间的交互。

```bash
pytest tests/ -m integration
```

### 安全测试 (Security Tests)

测试安全相关的功能。

```bash
pytest tests/test_security.py
```

## 测试夹具 (Fixtures)

### app

提供测试用的Flask应用实例。

```python
@pytest.fixture(scope='session')
def app():
    # 创建测试应用
    ...
```

### client

提供测试客户端。

```python
@pytest.fixture(scope='function')
def client(app):
    return app.test_client()
```

### sample_user

创建示例用户供测试使用。

```python
@pytest.fixture
def sample_user(db_session):
    user = User(name='测试用户', card_id='TEST001')
    db_session.add(user)
    db_session.commit()
    return user
```

## 编写新测试

### 基本结构

```python
import pytest
import json

class TestFeatureName:
    """功能名称测试"""
    
    def test_scenario(self, client, auth_headers):
        """测试场景描述"""
        response = client.get('/api/endpoint', headers=auth_headers)
        assert response.status_code == 200
```

### 使用数据库

```python
def test_with_database(self, client, db_session, sample_user):
    # 数据库操作
    user = User.query.get(sample_user.id)
    assert user is not None
```

### Mock外部依赖

```python
from unittest.mock import patch

def test_with_mock(self, client):
    with patch('mqtt_manager.publish') as mock_publish:
        mock_publish.return_value = True
        response = client.post('/api/mqtt/publish')
        mock_publish.assert_called_once()
```

## 持续集成

可以在 CI/CD 管道中运行测试：

```yaml
# .github/workflows/test.yml
name: Test

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: 3.9
      - name: Install dependencies
        run: |
          cd backend
          pip install -r requirements.txt
      - name: Run tests
        run: |
          cd backend
          pytest tests/ --cov=. --cov-report=xml
      - name: Upload coverage
        uses: codecov/codecov-action@v2
```

## 常见问题

### Q: 测试数据库如何初始化？

A: `conftest.py` 中的 `app` fixture 会自动创建内存数据库和测试管理员账户。

### Q: 如何跳过慢速测试？

A: 使用 `-m "not slow"` 可以跳过标记为 `slow` 的测试。

### Q: 如何只运行失败的测试？

A: 使用 `--lf` 参数：
```bash
pytest tests/ --lf
```

2. **修复Bug时添加回归测试**
3. **定期运行完整测试套件**
4. **保持测试快速执行（< 5分钟）**
5. **避免测试间的依赖关系**
