### 2. 发现的问题

#### 问题1: 配置重复 ⚠️

**问题描述**:
- `celery_config.py` 在根目录和 `startup/` 目录重复存在
- `start_celery.bat` 在根目录和 `startup/` 目录重复存在
- 两个 `celery_config.py` 中的配置项不完全一致

**解决方案**:
- 删除 `startup/celery_config.py`
- 删除 `startup/start_celery.bat`
- 统一使用根目录的配置和脚本

**结果**: ✅ 已解决

#### 问题2: Redis DB号不一致 ⚠️

**问题描述**:
- 根目录 `celery_config.py`: `redis://localhost:6379/0`
- `startup/celery_config.py`: `redis://localhost:6379/2`
- `redis_cache_service.py`: `REDIS_DB=0`

**解决方案**:
- 统一使用 `REDIS_DB=0`
- 在 `config.py` 中定义统一的 Redis 配置
- 所有组件引用 `config.py` 的 Redis 配置

**结果**: ✅ 已解决

#### 问题3: Celery任务路由不一致 ⚠️

**问题描述**:
- 根目录 `celery_config.py`: `'tasks.mqtt_tasks.*'`
- `startup/celery_config.py`: `'tasks.process_mqtt_message'`

**解决方案**:
- 统一使用通配符路由 `'tasks.mqtt_tasks.*'`
- 在 `config.py` 中定义统一的任务路由

**结果**: ✅ 已解决

#### 问题4: 启动脚本路径不一致 ⚠️

**问题描述**:
- 多个启动脚本使用不同的 Python 路径
- 启动命令和参数不统一

**解决方案**:
- 创建统一的启动脚本模板
- 所有脚本使用相同的 Python 路径
- 统一 Celery 启动参数

**结果**: ✅ 已解决

## 🚀 使用指南

### 1. 修改配置

编辑 `backend/.env` 文件:

```bash
# Flask配置
FLASK_SECRET_KEY=your_new_secret_key_at_least_32_chars
FLASK_ENV=production

# Redis配置
REDIS_HOST=your_redis_server
REDIS_PORT=6379
REDIS_DB=0

# JWT配置
JWT_SECRET_KEY=your_new_jwt_secret_key

# 备份配置
BACKUP_ENABLED=true
```

### 2. 验证配置

```bash
cd backend
python scripts/verify_config.py
```

### 3. 启动服务

```bash
# 启动后端
.\start.bat

# 启动Celery Worker (可选)
.\start_celery.bat

# 使用Gunicorn启动 (生产环境)
.\start_gunicorn.bat
```
