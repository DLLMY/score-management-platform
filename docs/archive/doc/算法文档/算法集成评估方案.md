```python
# ✨ 新增表：StudentCluster
class StudentCluster(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    cluster_label = db.Column(db.Integer, nullable=False)  # 聚类标签
    cluster_name = db.Column(db.String(50))  # 群体名称（如"全面优秀型"）
    behavior_score = db.Column(Float)  # 行为特征值
```

```python
# ✨ 新增表：RiskWarning
class RiskWarning(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    risk_level = db.Column(db.String(20), default='medium')  # low/medium/high

    is_resolved = db.Column(db.Boolean, default=False)
    resolved_at = db.Column(db.DateTime)
    created_at = db.Column(db.DateTime, default=datetime.now)

# ✨ 新增表：WarningConfig
class WarningConfig(db.Model):

    description = db.Column(db.String(200))
```

### 2.4 综合评分模块（熵权法）

**功能说明**：基于多维度指标，使用熵权法自动计算权重，生成综合评分

**新增API**：
- `GET /api/algorithm/composite-score` - 获取综合评分排名
- `POST /api/algorithm/composite-score` - 重新计算评分

**新增数据表**（需创建）：
```python
# ✨ 新增表：CompositeScore
class CompositeScore(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    behavior_weight = db.Column(Float)  # ✨ 行为维度权重(熵权法计算)
    academic_weight = db.Column(Float)  # ✨ 学业维度权重
    compliance_weight = db.Column(Float)  # ✨ 合规维度权重
    behavior_score = db.Column(Float)  # ✨ 标准化后行为得分
    academic_score = db.Column(Float)  # ✨ 标准化后学业得分
    compliance_score = db.Column(Float)  # ✨ 标准化后合规得分
    composite_score = db.Column(Float)  # ✨ 综合得分(0-100)
    ranking = db.Column(Integer)  # ✨ 综合排名
    created_at = db.Column(db.DateTime, default=datetime.now)
    updated_at = db.Column(db.DateTime, default=datetime.now)
```

**使用字段**：

## 六、系统限制与应对策略

| 限制 | 影响 | 应对策略 |
|------|------|---------|
| 无期中/前测数据 | 无法做时序预测 | 使用当前成绩做描述性分析，后续补充历史数据 |
| 行为维度单一 | 分群精度受限 | 先按积分总分分群，逐步拆分维度 |
| SQLite性能 | 大数据量分析慢 | 增加Redis缓存统计结果，定期更新 |
| Windows Server资源有限 | 模型训练资源受限 | 使用轻量算法（K-Means、逻辑回归） |
