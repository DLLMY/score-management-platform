# 📊 算法集成前端方案文档

---

## 一、方案概述

### 1.1 目标
本方案旨在为积分管理平台V2.0实现算法集成的前端展示层，包括统计分析、学生分群、综合评分和风险预警四大模块。

### 1.2 技术栈

| 层级 | 技术 | 版本 | 说明 |
|------|------|------|------|
| **框架** | React | 18+ | UI框架 |
| **构建工具** | Vite | 6+ | 构建工具 |
| **样式** | Tailwind CSS | 3+ | 原子化CSS |
| **图表** | recharts | 2+ | 数据可视化 |
| **图标** | lucide-react | 0.312+ | 图标库 |
| **路由** | React Router | 6+ | 路由管理 |

### 1.3 后端API接口

| API路径 | HTTP方法 | 功能描述 |
|---------|---------|---------|
| `/api/algorithm/statistics` | GET | 综合统计分析 |
| `/api/algorithm/cluster` | GET | 获取学生分群结果 |
| `/api/algorithm/cluster` | POST | 触发分群重新计算 |
| `/api/algorithm/cluster/{user_id}` | GET | 获取单个学生分群信息 |
| `/api/algorithm/composite-score` | GET | 获取综合评分排名 |
| `/api/algorithm/composite-score` | POST | 重新计算综合评分 |
| `/api/algorithm/composite-score/{user_id}` | GET | 获取单个学生综合评分 |
| `/api/algorithm/warning` | GET | 获取风险预警列表 |
| `/api/algorithm/warning` | POST | 执行风险评估 |
| `/api/algorithm/warning/{id}/resolve` | POST | 解决预警 |
| `/api/algorithm/warning/config` | GET | 获取预警配置 |
| `/api/algorithm/warning/config` | POST | 更新预警配置 |

## 二、API服务层扩展

### 2.1 修改文件
**文件**: `frontend/src/services/api.js`

### 2.2 添加代码

在`api`对象中添加以下模块：

```javascript
algorithm: {
  // 统计分析
  getStatistics: (params = {}) => {
    const query = new URLSearchParams(params).toString();
    return request(`/api/algorithm/statistics${query ? '?' + query : ''}`);
  },
  
  // 学生分群
  getClusters: (params = {}) => {
    const query = new URLSearchParams(params).toString();
    return request(`/api/algorithm/cluster${query ? '?' + query : ''}`);
  },
  recalculateClusters: () => request('/api/algorithm/cluster', { method: 'POST' }),
  getClusterByUser: (userId) => request(`/api/algorithm/cluster/${userId}`),
  
  // 综合评分
  getCompositeScores: (params = {}) => {
    const query = new URLSearchParams(params).toString();
    return request(`/api/algorithm/composite-score${query ? '?' + query : ''}`);
  },
  recalculateCompositeScores: () => request('/api/algorithm/composite-score', { method: 'POST' }),
  getCompositeScoreByUser: (userId) => request(`/api/algorithm/composite-score/${userId}`),
  
  // 风险预警
  getWarnings: (params = {}) => {
    const query = new URLSearchParams(params).toString();
    return request(`/api/algorithm/warning${query ? '?' + query : ''}`);
  },
  runWarningEvaluation: () => request('/api/algorithm/warning', { method: 'POST' }),
  resolveWarning: (id) => request(`/api/algorithm/warning/${id}/resolve`, { method: 'POST' }),
  getWarningConfig: () => request('/api/algorithm/warning/config'),
  updateWarningConfig: (data) => request('/api/algorithm/warning/config', {
    method: 'POST',
    body: JSON.stringify(data),
  }),
},
```

## 六、数据流设计

### 6.1 状态管理

| 状态 | 类型 | 说明 |
|------|------|------|
| `selectedClass` | string | 当前选中班级 |
| `activeTab` | string | 当前激活的Tab |
| `statistics` | object | 统计分析数据 |
| `clusters` | object | 分群数据 |
| `compositeScores` | array | 综合评分数据 |
| `warnings` | object | 预警数据 |
| `isLoading` | boolean | 加载状态 |
| `error` | string | 错误信息 |

### 6.2 数据流向

```
用户访问 /algorithm-analysis
    ↓
加载AlgorithmAnalysis组件
    ↓
触发并行API调用
    ├── api.algorithm.getStatistics()
    ├── api.algorithm.getClusters()
    ├── api.algorithm.getCompositeScores()
    └── api.algorithm.getWarnings()
    ↓
数据缓存到组件state
    ↓
渲染各Tab面板
    ↓
用户交互（筛选/重新计算）
    ↓
触发对应API更新
    ↓
更新state并重新渲染
```
