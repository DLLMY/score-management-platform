## 📋 一、系统概述

本方案采用 **发布/订阅 (Pub/Sub)** 模型，通过 MQTT 协议在控制端和被控电脑之间传递指令。被控电脑作为 MQTT 客户端，订阅特定主题，接收来自控制端的 JSON 指令，执行以下动作：

- **全屏置顶弹窗**（Tkinter）
- **文字转语音播报**（pyttsx3）
- **系统音量调节**（pycaw，仅 Windows）

控制端可以是手机 App、Python 脚本或任何支持 MQTT 的设备，无需公网 IP 或端口转发，只要有互联网连接即可。

**系统特点：**
- ✅ 无内网穿透需求，所有设备主动连接云端 MQTT 代理（Broker）
- ✅ 支持公共免费 Broker，零成本入门
- ✅ 可扩展为私有 Broker 或 ZeroTier 虚拟局域网
- ✅ 弹窗醒目（全屏、黑底红字、定时关闭）
- ✅ 支持远程调节系统音量，保证语音提醒足够响亮
- ✅ 简单易用的 JSON 指令格式

### 2. 核心功能模块 `notifier.py`
```python
import threading
import tkinter as tk
import pyttsx3
from pycaw.pycaw import AudioUtilities, IAudioEndpointVolume
from comtypes import CLSCTX_ALL

# ---------- 1. 音量控制 (Windows) ----------
def set_volume(level: float) -> bool:
    """
    设置系统主音量 (0.0 ~ 1.0)
    """
    try:
        devices = AudioUtilities.GetSpeakers()
        interface = devices.Activate(IAudioEndpointVolume._iid_, CLSCTX_ALL, None)
        volume = interface.QueryInterface(IAudioEndpointVolume)
        volume.SetMasterVolumeLevelScalar(max(0.0, min(1.0, level)), None)
        return True
    except Exception as e:
        print(f"[音量] 设置失败: {e}")
        return False

# ---------- 2. TTS 引擎（全局单例） ----------
_tts_engine = None

def get_tts_engine():
    global _tts_engine
    if _tts_engine is None:
        _tts_engine = pyttsx3.init()
        # 尝试设置为中文语音
        voices = _tts_engine.getProperty('voices')
        for voice in voices:
            if 'chinese' in voice.name.lower():
                _tts_engine.setProperty('voice', voice.id)
                break
        _tts_engine.setProperty('rate', 150)   # 语速
        _tts_engine.setProperty('volume', 1.0) # 播报音量最大
    return _tts_engine

def speak_text(text: str):
    """在新线程中播放语音"""
    def _speak():
        engine = get_tts_engine()
        engine.say(text)
        engine.runAndWait()
    threading.Thread(target=_speak, daemon=True).start()

# ---------- 3. 全屏弹窗 ----------
def fullscreen_popup(message: str, timeout_sec: int = 8):
    """
    显示全屏置顶弹窗，自动关闭
    """
    def _popup():
        root = tk.Tk()
        root.attributes('-fullscreen', True)
        root.attributes('-topmost', True)
        root.configure(bg='black')
        
        frame = tk.Frame(root, bg='black')
        frame.place(relx=0.5, rely=0.5, anchor='center')
        
        label = tk.Label(frame, text=message,
                         font=('微软雅黑', 48, 'bold'),
                         fg='red', bg='black')
        label.pack(padx=30, pady=30)
        
        btn = tk.Button(frame, text='关闭', font=('微软雅黑', 20),
                        command=root.destroy, bg='gray', fg='white')
        btn.pack(pady=20)
        
        root.after(timeout_sec * 1000, root.destroy)
        root.mainloop()
    
    threading.Thread(target=_popup, daemon=True).start()
```

### 3. MQTT 监听客户端 `mqtt_listener.py`（在被控电脑上运行）
```python
import paho.mqtt.client as mqtt
import json
from notifier import set_volume, fullscreen_popup, speak_text

# ========== 配置区域 ==========
MQTT_BROKER = "broker.emqx.io"   # 公共 MQTT 代理地址
MQTT_PORT = 1883
MQTT_TOPIC = "remote/notify"     # 可改成更私密的名称，如 "home/office/notify_xxx"
# ==============================

def on_connect(client, userdata, flags, rc):
    if rc == 0:
        print("✅ 已连接到 MQTT Broker")
        client.subscribe(MQTT_TOPIC)
        print(f"📡 订阅主题: {MQTT_TOPIC}")
    else:
        print(f"❌ 连接失败，返回码: {rc}")

def on_message(client, userdata, msg):
    try:
        payload = msg.payload.decode('utf-8')
        print(f"📨 收到指令: {payload}")
        data = json.loads(payload)
        
        # 提取参数
        text = data.get('text', '')
        if not text:
            print("⚠️ 无效指令：缺少 text 字段")
            return
        
        # 1. 调节音量（如果提供了 volume 字段）
        if 'volume' in data:
            set_volume(float(data['volume']))
        
        # 2. 弹窗
        if data.get('popup', True):
            fullscreen_popup(text)
        
        # 3. 语音播报
        if data.get('speak', True):
            speak_text(text)
            
    except Exception as e:
        print(f"❌ 处理消息出错: {e}")

# 创建 MQTT 客户端
client = mqtt.Client()
client.on_connect = on_connect
client.on_message = on_message

# 连接并启动循环
client.connect(MQTT_BROKER, MQTT_PORT, 60)
print("🚀 远程通知系统已启动，等待指令...")
client.loop_forever()
```

### 4. 控制端发送示例 `mqtt_publisher.py`
```python
import paho.mqtt.client as mqtt
import json

# 配置（必须与监听端相同）
MQTT_BROKER = "broker.emqx.io"
MQTT_PORT = 1883
MQTT_TOPIC = "remote/notify"

# 通知内容
message = {
    "text": "紧急会议，请立即查看！",
    "volume": 0.8,       # 80% 音量
    "speak": True,
    "popup": True
}

client = mqtt.Client()
client.connect(MQTT_BROKER, MQTT_PORT, 60)
client.publish(MQTT_TOPIC, json.dumps(message))
client.disconnect()
print("✅ 通知指令已发送")
```

## 🚀 五、部署与使用步骤

### 1. 在被控电脑上安装环境
- 安装 Python 3.8+
- 打开命令提示符，执行：
  ```bash
  pip install paho-mqtt pyttsx3 pycaw comtypes
  ```
- 将上述 `notifier.py` 和 `mqtt_listener.py` 放在同一目录下。

### 2. 运行监听服务
```bash
python mqtt_listener.py
```
正常输出：
```
🚀 远程通知系统已启动，等待指令...
✅ 已连接到 MQTT Broker
📡 订阅主题: remote/notify
```

**保持此命令行窗口打开**（或设为后台运行、开机自启）。

### 3. 发送测试指令
- 在同一局域网或任意有互联网的设备上，运行 `mqtt_publisher.py`（修改其中的 text 内容）。
- 或者使用手机 App **MQTT Dash**（Android/iOS）：
  - 添加 Broker：`broker.emqx.io:1883`
  - 发布主题：`remote/notify`
  - 消息体（JSON）：
    ```json
    {"text":"测试弹窗","volume":0.9,"speak":true,"popup":true}
    ```
  - 点击发布，被控电脑应立即弹出全屏通知并语音播报。

### 4. 设置开机自启（Windows）
- 创建一个批处理文件 `start_listener.bat`，内容：
  ```batch
  @echo off
  python C:\path\to\mqtt_listener.py
  ```
- 按 `Win + R`，输入 `shell:startup`，将批处理文件快捷方式放入该文件夹。
- 下次电脑启动时会自动运行监听服务（需要登录桌面才会启动 GUI 相关组件，若需无登录启动，可考虑注册为系统服务，但较复杂）。

## 🔊 六、音量控制与弹窗说明

- **音量**：指令中的 `volume` 取值范围 `0.0` ~ `1.0`。如果不提供该字段，则不改变当前音量。
- **弹窗**：默认显示 8 秒，右上角有关闭按钮。如果连续收到多条通知，会依次弹出（每个弹窗独立线程）。
- **语音**：使用系统 TTS，支持中文（需系统安装中文语音包，Win10/11 默认支持）。语速可在 `notifier.py` 中修改 `setProperty('rate', 150)`。

## 🔌 七、远程开机扩展（可选）

由于 MQTT 无法直接发送魔术包，可以借助**另一台常开设备**（如树莓派、NAS、闲置手机）作为中介：

### 方案 A：使用常开设备运行 WOL 接收器
在该设备上运行一个简单的 MQTT 订阅脚本，当收到特定主题的消息（如 `wake/pc`）时，执行 `wakeonlan` 命令发送魔术包。

示例代码（中介设备）：
```python
import paho.mqtt.client as mqtt
from wakeonlan import send_magic_packet

MAC = "AA:BB:CC:DD:EE:FF"   # 被控电脑的 MAC 地址

def on_message(client, userdata, msg):
    if msg.payload.decode() == "wake":
        send_magic_packet(MAC)
        print("已发送魔术包")

client = mqtt.Client()
client.on_message = on_message
client.connect("broker.emqx.io", 1883)
client.subscribe("wake/pc")
client.loop_forever()
```

### 方案 B：使用智能插座 + BIOS 通电自启
- 将电脑电源插头接在智能插座上，BIOS 设置“通电自启”。
- 通过 MQTT 控制智能插座（部分插座支持 MQTT，或通过 Home Assistant 中转），远程断电再通电即可开机。

## 🔒 八、安全与隐私建议

使用公共 Broker（`broker.emqx.io`）时，**所有消息都是公开的**。建议采取以下措施：

1. **使用私有主题**：将 `MQTT_TOPIC` 改为难以猜测的字符串，例如：
   ```python
   MQTT_TOPIC = "abc123xyz/private/notify"
   ```
2. **消息加密**：在发送前对 JSON 进行 AES 加密，接收端解密。库推荐 `pycryptodome`。
3. **升级为私有 Broker**：
   - 在家庭服务器或树莓派上使用 Docker 部署 EMQX：
     ```bash
     docker run -d --name emqx -p 1883:1883 -p 8083:8083 emqx/emqx:latest
     ```
   - 配合 ZeroTier 或 Tailscale 组建虚拟局域网，让所有设备通过内网 IP 连接私有 Broker，彻底避免公网暴露。

## 🛠️ 九、故障排查常见问题

| 现象                         | 可能原因及解决方法                                         |
| ---------------------------- | ---------------------------------------------------------- |
| 连接 Broker 失败             | 检查网络是否能访问 `broker.emqx.io:1883`（防火墙或运营商限制） |
| 订阅成功但收不到消息         | 确认控制端发布使用的主题与监听端订阅的主题**完全一致**（包括大小写） |
| 弹窗不显示                   | 确保被控电脑有 GUI 桌面环境（Windows 必须已登录桌面）        |
| 语音无声或不是中文           | 检查系统是否安装中文语音包；在 `notifier.py` 中调整 voice 匹配逻辑 |
| 音量控制无效                 | 仅支持 Windows；尝试以管理员身份运行 `mqtt_listener.py`      |
| 开机自启后脚本未运行         | 因为 Tkinter 弹窗需要桌面环境，若设置为开机启动但未登录，弹窗不会显示。建议保持电脑登录状态或使用其他无 GUI 通知方式 |

## 📈 十、扩展功能思路

- **定时通知**：在控制端用 `schedule` 或 `cron` 定时发布消息。
- **多台电脑群控**：不同电脑订阅不同的主题（如 `office/pc1`、`office/pc2`），或使用通配符一次性通知所有设备。
- **带图片/网页的弹窗**：修改 `notifier.py` 中的弹窗部分，将 `tkinter.Label` 替换为 `tkinter.Canvas` 并加载图片，或嵌入 HTML（可用 `cefpython3` 但较复杂）。
- **状态回传**：被控电脑接收到指令后，向另一个主题发送“已执行”状态，便于控制端确认。

## ✅ 十一、总结

本方案提供了一个 **无需内网穿透**、**部署简单**、**功能完整** 的远程通知系统。你只需要在被控电脑上运行一个 Python 脚本，即可通过任何 MQTT 客户端（手机/电脑）发送 JSON 指令，触发全屏弹窗和语音提醒。

- **入门最快**：使用公共 Broker + 手机 MQTT App，5 分钟内即可体验。
- **进阶安全**：自建私有 Broker + ZeroTier 虚拟组网，完全控制数据流。

你可以根据实际网络环境选择最适合的方式，整个系统代码完全开源可控，方便按需定制。
