# 学生积分管理系统 - 完整项目说明

基于 **Flask + React + TypeScript** 构建的全栈积分管理平台，支持设备管理、积分规则、成绩分析、远程通知等功能。

---

## 📋 项目概述

本系统是一个面向教育机构的积分管理平台，通过智能硬件设备（积分盒）自动采集学生行为数据，结合灵活的积分规则引擎，实现学生综合素质评价的数字化管理。系统支持多维度数据分析、远程设备控制、跨设备通知等高级功能。

### 核心特性

- 🎯 **智能积分采集** - 通过硬件设备自动记录学生行为，支持刷卡、扫码等多种采集方式
- 📊 **多维度数据分析** - 积分趋势、班级对比、算法分析、成绩关联分析
- 🔧 **设备全生命周期管理** - 设备监控、固件升级、远程开机、MQTT调试
- 🔔 **远程通知系统** - 基于MQTT的跨设备通知，支持弹窗、语音播报、音量控制
- 📝 **灵活的规则引擎** - 积分规则、排名规则、分类管理、时间规则
- 🏆 **成绩管理** - 考试管理、成绩录入、成绩档案、成绩分析
- 🔒 **完善的权限体系** - RBAC权限控制、操作审计、子账户管理
- 🚀 **高性能架构** - Redis缓存、请求优化、代码分割、Docker部署

### 8. 远程通知系统

**架构说明**：
```
管理平台
    ↓ HTTP
后端API (remote_notify_routes.py)
    ↓ MQTT
MQTT Broker (EMQX)
    ↓ MQTT订阅
远程客户端 (mqtt_listener.py)
    ↓
弹窗显示 + 语音播报 (notifier.py)
```

**客户端安装**：
```bash
cd remote_notify
install.bat  # Windows服务安装
```

**通知参数**：
- `text`: 通知文本
- `volume`: 音量（0.0-1.0）
- `speak`: 是否语音播报
- `popup`: 是否显示弹窗
- `timeout_sec`: 自动关闭时间（秒）
- `urgent`: 是否紧急通知

## 🐛 常见问题

### Q1: 后端启动失败，提示端口被占用
**解决方法**：
```bash
# Windows
netstat -ano | findstr :5000
taskkill /PID <进程ID> /F

# Linux/Mac
lsof -i :5000
kill -9 <进程ID>
```

### Q2: Redis连接失败
**解决方法**：
1. 检查Redis服务是否启动
2. 检查Redis配置（host、port、password）
3. 使用 `redis-cli ping` 测试连接

### Q3: MQTT连接失败
**解决方法**：
1. 检查MQTT Broker地址是否正确
2. 检查网络连接
3. 检查用户名密码是否正确

### Q4: 前端编译报错
**解决方法**：
```bash
cd frontend
rm -rf node_modules package-lock.json
npm install
npm run build
```
