# 远程通知接收端部署指南

## 快速开始

### 方法一：全新安装（推荐 - 适合无 Python 环境）

**完全自动化，无需任何预先配置**

1. **双击运行** `install_full.bat`
2. 等待脚本自动完成以下操作：
   - 下载并安装 Python 3.11.4（约 27MB）
   - 安装所有依赖包
   - 创建启动脚本
   - 创建桌面快捷方式

3. **启动程序**：
   - 双击桌面的「远程通知接收端」快捷方式
   - 或运行 `run_minimized.bat`（后台运行）

---

### 方法二：简易安装（适合已有 Python 环境）

1. **双击运行** `install_easy.bat`
2. 脚本会自动：
   - 检测系统中的 Python
   - 安装必要的依赖
   - 创建启动脚本

3. **运行**：`run.bat` 或 `run_minimized.bat`

---

### 方法三：手动部署

1. **安装 Python 3.8+**
   - 下载地址：https://www.python.org/downloads/windows/
   - 安装时务必勾选 "Add Python to PATH"

2. **安装依赖**
   ```cmd
   pip install paho-mqtt==1.6.1 pyttsx3==2.90 pycaw==20230408 comtypes==1.2.0
   ```

3. **运行监听程序**
   ```cmd
   cd /d "C:\path\to\remote_notify"
   python -u mqtt_listener.py
   ```

4. **测试通知**
   - 运行后会显示 Client ID（如 `client_xxx`）
   - 在管理平台发送通知时使用此 Client ID

---

### 方法四：Windows 服务安装（需要管理员）

**注意**：需要以管理员身份运行

1. **右键点击** `install.bat`
2. 选择 **以管理员身份运行**
3. 等待安装完成（约5-10分钟）
4. 服务会自动启动并在系统开机时运行

---

## 故障排除

### 常见错误

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| Python 下载失败 | 网络问题 | 检查网络连接或手动下载 Python |
| 依赖安装失败 | 网络问题 | 检查网络或使用手动安装方法 |
| 服务启动失败 | 路径包含中文或空格 | 将文件夹移动到纯英文路径 |
| TTS 无声音 | pyttsx3 未正确配置 | 运行 `python -c "import pyttsx3; engine = pyttsx3.init(); engine.say('测试')"` |
| 程序闪退 | 缺少依赖 | 重新运行安装脚本 |

### 日志文件

- **安装日志**：`install.log` - 记录安装过程
- **服务日志**：`service.log` - 记录运行状态和 Client ID

### 手动启动服务

```cmd
# 启动服务
net start RemoteNotifyListener

# 停止服务
net stop RemoteNotifyListener

# 查看服务状态
sc query RemoteNotifyListener
```

### 卸载服务

运行 `uninstall.bat` 或执行：
```cmd
sc stop RemoteNotifyListener
sc delete RemoteNotifyListener
```

## 配置说明

### MQTT 连接信息

默认配置（可在 `mqtt_listener.py` 中修改）：
- **服务器**：localhost
- **端口**：1883
- **主题**：`notify/{client_id}`

### Client ID

每个客户端会自动生成唯一的 Client ID，格式为 `client_<随机字符串>`。在管理平台发送通知时需要指定目标 Client ID。

## 目录结构

```
remote_notify/
├── mqtt_listener.py       # 主监听程序
├── notifier.py            # 通知处理模块
├── install_full.bat       # 全新安装（自动下载 Python）
├── install_easy.bat       # 简易安装（使用系统 Python）
├── install.bat            # 服务安装（需管理员）
├── uninstall.bat          # 卸载脚本
├── start_listener.bat     # 手动启动脚本
├── run_silent.vbs         # 静默运行脚本
├── requirements.txt       # 依赖列表
└── DEPLOYMENT_GUIDE.md    # 部署指南
```

### 安装脚本对比

| 脚本 | 需要 Python | 需要管理员 | 特点 |
|------|------------|-----------|------|
| `install_full.bat` | ❌ | ❌ | 自动下载 Python，完全独立 |
| `install_easy.bat` | ✅ | ❌ | 使用系统 Python，快速安装 |
| `install.bat` | ❌ | ✅ | 安装为 Windows 服务 |

## 技术支持

如果遇到问题，请检查：
1. 网络连接正常（需要访问 python.org 和 pypi.org）
2. 防火墙允许出站连接
3. 运行目录权限足够（建议放在 `D:\remote_notify` 等简单路径）
4. 路径不要包含中文或特殊字符
