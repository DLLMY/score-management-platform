# 门禁系统 - 必需库安装说明

## 📚 必需库列表

请在 Arduino IDE 库管理器中安装以下库：

### 1. LiquidCrystal_I2C (必需！)

- **库名称**: LiquidCrystal I2C
- **作者**: Marco Schwartz
- **版本**: 1.1.4 或更高
- **用途**: 驱动 I2C LCD1602 显示屏

**安装步骤**:
1. 打开 Arduino IDE
2. 点击 **工具** → **管理库** (或按 `Ctrl+Shift+I`)
3. 在搜索框输入 `LiquidCrystal I2C`
4. 找到 **Marco Schwartz** 的版本
5. 点击 **安装**

### 2. PubSubClient (必需！)

- **库名称**: PubSubClient
- **作者**: Nick O'Donovan
- **版本**: 2.8 或更高
- **用途**: MQTT 客户端库

**安装步骤**:
1. 库管理器中搜索 `PubSubClient`
2. 找到 **Nick O'Donovan** 的版本
3. 点击 **安装**

## ⚠️ 常见错误

### 错误 1: 安装了错误的库

❌ **不要安装**: `Adafruit PCF8574`
- 这是用于 GPIO 扩展的库
- 不能用于 LCD 显示

✅ **应该安装**: `LiquidCrystal_I2C` by Marco Schwartz
- 专门用于 LCD1602 I2C 模块
- 内置 PCF8574 驱动

### 错误 2: LCD 不显示

**可能原因**:
1. I2C 地址不对
   - 尝试 `0x27` (PCF8574T)
   - 尝试 `0x3F` (PCF8574AT)
   
2. 接线问题
   - 检查 SDA 是否接 GPIO18
   - 检查 SCL 是否接 GPIO19
   - 检查 VCC 是否接 5V
   - 检查 GND 是否接 GND

3. 对比度问题
   - 旋转 LCD 模块上的电位器（蓝色方块）
   - 调整到合适的对比度

## 🔧 I2C 地址检测

代码已自动集成 I2C 地址检测功能：

1. 上传代码后打开串口监视器（115200 波特率）
2. 查看 `[2/7] 初始化 LCD...` 部分
3. 会显示检测到的 LCD 地址

**示例输出**:
```
[2/7] 初始化 LCD...
      检测 LCD 地址... 找到 LCD，地址：0x27
      LCD 初始化成功
```

## 📌 硬件连接

### ESP32-S3-N8R2 ↔ LCD1602 I2C

| ESP32 引脚 | LCD 引脚 | 说明 |
|:----------:|:--------:|------|
| GPIO18     | SDA      | I2C 数据 |
| GPIO19     | SCL      | I2C 时钟 |
| 5V         | VCC      | 电源正极 |
| GND        | GND      | 电源负极 |

### 注意事项

1. **电源**: LCD1602 I2C 模块使用 5V 供电
2. **上拉电阻**: I2C 总线需要 4.7kΩ上拉电阻（部分模块已内置）
3. **引脚兼容**: ESP32-S3 的 GPIO18/19 支持 I2C 功能

## ✅ 验证安装

安装完成后，上传代码并观察：

1. **串口输出**: 应显示 LCD 地址和初始化成功信息
2. **LCD 背光**: 应该亮起
3. **LCD 显示**: 应显示"系统就绪"等中文内容

如果一切正常，说明库安装正确！
