# 门禁系统 (DoorLock)

基于ESP32-S3的智能门禁系统，支持密码开门、刷卡开门、积分查询与管理。

## 功能特性

- ✅ 密码开门（6位密码）
- ✅ 刷卡开门（RFID本地验证）
- ✅ 积分查询（MQTT远程）
- ✅ 积分增加/减少（MQTT远程）
- ✅ 中文LCD显示（1602 LCD）
- ✅ WiFi配网（AP模式 + Captive Portal）
- ✅ MQTT通信（SSL加密）
- ✅ OTA远程升级
- ✅ 超时自动返回

| ESP32引脚 | 外设 | 功能 |
|:---|:---|:---|
| GPIO4-GPIO7 | 键盘R1-R4 | 行线输入 |
| GPIO8-GPIO10 | 键盘C1-C3 | 列线输出 |
| GPIO21 | LCD SDA | I2C数据 |
| GPIO22 | LCD SCL | I2C时钟 |
| GPIO16 | RFID TX | UART接收 |
| GPIO17 | RFID RX | UART发送 |
| GPIO5 | 继电器 | 门锁控制 |
| GPIO25 | 红色LED | 错误指示 |
| GPIO26 | 绿色LED | 成功指示 |
| GPIO27 | 蜂鸣器 | 声音提示 |
| GPIO15 | 配置按键 | 长按配网 |

## 快速开始

### 1. 硬件连接

按照上述引脚分配连接硬件。

### 2. 首次配网

1. 设备上电后自动进入配网模式
2. 手机连接WiFi热点 `DoorLock-Config`（密码：`12345678`）
3. 浏览器自动弹出配网页面，填写WiFi和MQTT配置
4. 保存配置后设备自动重启

### 3. 操作说明

| 状态 | 操作 |
|:---|:---|
| 初始状态 | 按`*`进入密码模式，或刷卡开门 |
| 密码模式 | 输入6位密码，按`#`确认 |
| 菜单模式 | 按`1`查询积分，`2`增加积分，`3`减少积分，`4`退出 |
