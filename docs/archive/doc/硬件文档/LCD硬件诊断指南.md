# LCD1602 I2C 硬件诊断指南

## ⚠️ 当前问题

根据串口日志显示：
```
[2/7] 初始化 LCD...
      检测 LCD 地址... 未找到 LCD!
```

I2C 总线上没有检测到任何设备，请按照以下步骤排查：

---

## 🔌 步骤 1: 检查接线

### 正确接线表

| ESP32-S3 引脚 | LCD I2C 模块 | 说明 |
|:-------------:|:-----------:|------|
| **GPIO18** | SDA | I2C 数据线 |
| **GPIO19** | SCL | I2C 时钟线 |
| **5V** | VCC | 电源正极（必须5V！） |
| **GND** | GND | 电源负极 |

### 接线图

```
ESP32-S3          LCD I2C 模块
──────────────────────────────
GPIO18 ────────────> SDA
GPIO19 ────────────> SCL
5V ────────────────> VCC
GND ───────────────> GND
```

### 检查要点

1. **确认引脚连接正确**
   - SDA → GPIO18（不是其他引脚！）
   - SCL → GPIO19（不是其他引脚！）

2. **确认电源线**
   - LCD 模块必须接 **5V**，不能接 3.3V（背光可能不亮）
   - GND 必须可靠连接

3. **检查线缆质量**
   - 使用高质量杜邦线
   - 避免过长的线缆（建议 < 30cm）

---

## 🔋 步骤 2: 检查供电

### 常见问题

1. **LCD 模块不亮**
   - 检查 5V 电源是否正常
   - 检查背光引脚（有些模块有独立背光控制）

2. **电源不足**
   - 如果使用 USB 供电，确保电流足够（至少 500mA）
   - 尝试使用外部电源

---

## 🔍 步骤 3: 检查 I2C 地址

### 自动扫描

代码已添加 I2C 扫描功能，上传新代码后查看串口输出：

```
[2/7] 初始化 LCD...
      检测 LCD 地址... 未找到 LCD!
      正在扫描 I2C 总线...
      找到设备: 0x27
        (可能是 PCF8574 LCD I2C)
```

### 常见地址

| 地址 | 说明 |
|------|------|
| 0x27 | PCF8574T 芯片（最常见） |
| 0x3F | PCF8574AT 芯片 |
| 0x20-0x26 | 其他 PCF8574 地址 |
| 0x38-0x3E | 其他 PCF8574AT 地址 |

### 如果扫描到设备但 LCD 仍不显示

1. 记下检测到的地址
2. 检查对比度电位器
3. 尝试手动设置地址

---

## ⚙️ 步骤 4: 检查硬件设置

### 对比度调节

LCD 模块上有一个蓝色电位器，用于调节对比度：
- 顺时针旋转：对比度增加
- 逆时针旋转：对比度降低

**操作**：上电后缓慢旋转电位器，观察屏幕变化

### 模块型号确认

确认你的 LCD 模块类型：
- **PCF8574 转接板**：常见的蓝色/绿色模块
- **直接 I2C 模块**：集成了 I2C 芯片的模块

### 上拉电阻

I2C 总线需要上拉电阻（通常 4.7kΩ）：
- 大部分模块已内置上拉电阻
- 如果没有，需要外接上拉电阻

---

## ✅ 步骤 5: 测试连接

### 硬件测试方法

1. **万用表测试**
   - 测量 VCC-GND：应为 5V
   - 测量 SDA/SCL 在空闲状态：应为高电平（约 3.3V）

2. **示波器测试**（可选）
   - SCL 应有时钟信号
   - SDA 应有数据信号

### 软件测试

上传代码后，查看串口监视器（115200 波特率）：

```
===== 门禁系统启动 =====
[1/7] 初始化引脚...
[2/7] 初始化 LCD...
      检测 LCD 地址... 找到 LCD，地址：0x27
      LCD 初始化成功
[3/7] 创建中文字符...
...
```

## 🔧 如果问题仍然存在

1. **更换模块**：尝试使用已知良好的 LCD 模块
2. **更换引脚**：尝试使用其他 I2C 引脚（GPIO4/GPIO5）
3. **检查焊接**：如果是自己焊接的转接板，检查焊点
4. **使用其他库**：尝试使用 Adafruit_LiquidCrystal 库测试
