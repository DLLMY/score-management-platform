## 3. 本轮新增修复

### 3.1 真实 Bug：日期/时间字符串未解析（2 处）
**根因**：`Exam`（考试）与 `Attendance`（考勤）模型字段为 `db.DateTime / db.Date` 类型，但接口直接把 JSON 字符串原样写入，触发 SQLite 类型错误 → 500。

**修复**：新增共享工具 `backend/utils/datetime_utils.py`
- `parse_date(value)`：兼容 `2026-09-01` / `2026/09/01` / ISO 日期；空或非法返回 `None`
- `parse_datetime(value)`：兼容 `2026-09-01 09:00:00`、`2026-09-01T09:00:00`、`2026/09/01 09:00:00`、仅日期、仅 `HH:MM`（取当天）等；空或非法返回 `None`

应用位置：
- `backend/api/academics/exam_routes.py`：`post` 创建与 `put` 更新中 `date/start_time/end_time` 均经 `parse_*`
- `backend/services/attendance_service.py`：`record_attendance` 与 `batch_record` 中 `date/arrive_time/leave_time` 均经 `parse_*`

**端到端确认（经前端代理 3000）**：
- `POST /api/exams`（含 `date/start_time/end_time` 字符串）→ `200 创建成功`，落库日期正确
- `POST /api/attendance/records`（含 `date/arrive_time/leave_time` 字符串）→ `201`
- `POST /api/attendance/batch`（包装体 `{"records":[...]}`，含日期字符串）→ `200`，`count:1`

### 3.2 健壮性加固：缺必填字段返回 400 而非 500
发现 `committee_service.create_member` 与 `attendance_service.record_attendance / batch_record` 用 `data["字段"]` 硬取值，漏传必填字段时抛 `KeyError` → 500（对前端不友好）。已统一加固为参数校验，缺字段返回结构化 `400`：

- `backend/services/committee_service.py`：`create_member` 校验 `class_id/position/student_id`
- `backend/services/attendance_service.py`：`record_attendance` 与 `batch_record` 校验 `class_id/student_id`

**确认**：缺 `student_id` 的 `POST /api/committee/members` → `400 {"message":"缺少必填字段: student_id"}`；缺 `class_id` 的 `POST /api/attendance/records` 与批量 → `400`（批量会指出第几条缺字段）。

## 6. 进程与配置卫生（踩坑经验）
1. **后端必须用 venv Python**：`backend/.venv/Scripts/python.exe`（系统 Python 3.11 缺 torch/transformers，会导致启动失败）。
2. **务必先杀干净旧 `run.py` 进程**再重启，否则评估会命中旧代码（曾发现 5004/5005 被僵尸进程占用）。
3. **开发服务器用 `threaded=True`**：单线程 dev server 下一个挂起的写端点会阻塞后续所有请求；threaded 模式可避免批量测试时雪崩。
4. **`debug=True` 会启用 reloader**：修改被 import 的源码（如 `committee_service.py`）会触发自动重启，批量测试期间可能出现短暂不可用窗口——属正常现象，重启后新代码即生效。
5. **测试脚本严禁 `from app import app`**：会触发完整 ML 模型加载（约 90s）；改用静态用例列表 + `urllib` 直发 HTTP。
6. **测试载荷需贴近真实字段**：角色 `permissions` 为逗号字符串（`score:view,user:view`）；考勤批量接口入参为包装体 `{"records":[...]}`；家委/考勤需 `student_id`/`class_id`。
