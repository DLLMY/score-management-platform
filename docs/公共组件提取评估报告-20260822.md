### 6.2 目录结构规范（新增公共组件遵守）

```
frontend/src/
  utils/         # 纯函数工具（无 React 依赖）：format.ts, logger.ts, validation.ts ...
  components/ui/ # 原子 UI 组件（纯展示，props in）：StatusTag.tsx, Button.tsx ...
  components/index.ts + ui/index.ts  # 统一 barrel 导出，禁止页面深层相对路径
  hooks/         # 复用型 hooks：useListFetch.ts, useOptimizedFetch.ts ...
                 # 每个 hook 单一职责，依赖仅下层（services/utils）
backend/
  utils/         # 跨域纯逻辑：params.py, permission.py, pagination.py, response.py
  services/      # 防腐层 + 序列化（实体→dict 的单一真相源放此处）
  api/           # 路由层只做：get_or_404 / 校验 / 缓存失效 / 副作用 / 响应构造
```

### 6.3 依赖方向（禁止回环）

```
页面/路由（顶层）
   ↓ 依赖
hooks / components / utils（中层，可互引但单向）
   ↓ 依赖
services（防腐层，含序列化）
   ↓ 依赖
models / DB（底层）
```

- 规则：**下层禁止 import 上层**（如 `utils/` 不得 import `api/`；`services/` 不得 import `hooks/`）。
- 公共组件自身不得产生副作用（不发请求、不写 DB、不改全局状态），状态与副作用由调用方注入。
