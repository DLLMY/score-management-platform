## 三、未处理项与备注

1. **gitignore 内残留文件未删除**：`_cleanup_backup_20260803/`、`frontend_run.log`、`nul` 等被 `.gitignore` 忽略的文件，因本轮删除数累计触发安全删除钩子（>50 阈值）被拦截，未强制删除。它们不影响 git 提交，属可选磁盘清理，需单独确认后处理。
2. **`tsc --noEmit` 预先存在的版本不一致**：`tsconfig.json` 使用了 `moduleResolution: "bundler"`、`allowImportingTsExtensions`、`noUncheckedSideEffectImports`（均 TS 5.x 选项），但 `package.json` 锁定 `typescript ^4.9.5`，导致类型检查无法运行。建议将 `typescript` 升级到 `^5.x` 或把 `moduleResolution` 改为 `node`，以恢复类型检查闸门（非本次整理范围）。
3. **前端 7 个遗留 `.js` 文件保留**：`src/hooks/usePerformance.js`、`useWebSocket.js`、`stores/asyncStore.js`、`utils/toast.js`、`webVitals.js`、`setupTests.js`、`services/__tests__/api.test.js`。因 `tsconfig` 开启 `allowJs`，运行正常；可后续择机转为 `.ts`（属次要命名不一致，本次未动）。
4. **部署大二进制保留**：`ngrok/*.zip`（12MB）+ `redis/*`（约 10MB）共约 22MB 第三方二进制，按你的选择继续跟踪（离线部署依赖）。如需减小仓库，可改由 `download_deps.py` 拉取并加入 `.gitignore`。
5. **CSS 拼写告警**：`backgroundposition` 应为 `background-position`，位于某 CSS 中，与本次清理无关，建议后续修正。
