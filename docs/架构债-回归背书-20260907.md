## 三、环境前提（此前长期阻塞回归的根因）

此前判定「沙箱不可跑」，实际是**系统 Python 3.11 主环境损坏**：

1. `site-packages` 中 `werkzeug-2.3.7.dist-info` 与 `werkzeug-3.1.8.dist-info` **并存**，
   实际 `werkzeug/urls.py` 为 3.x 代码（无 `url_quote`）→ `import flask`(2.2.2) 直接 ImportError。
   pip 元数据仍显示 2.3.7，**极具迷惑性**。
2. 缺失：`SQLAlchemy` / `Flask-SQLAlchemy` / `greenlet` / `prometheus-client` /
   `packaging`(flasgger) / `attrs` / `certifi` / `urllib3` / `charset_normalizer` / `idna`。

### 修复方案（零污染主环境）

```bash
python -m venv --system-site-packages backend/.venv   # 继承 torch 2.11 等重量包
.venv/Scripts/python.exe -m pip install "SQLAlchemy>=1.4,<2.1" "Flask-SQLAlchemy>=3.0" \
    greenlet "prometheus-client>=0.19" packaging certifi urllib3 attrs charset_normalizer idna
```

- venv 内 Flask 自动升至 **2.3.3**（Flask-SQLAlchemy 3.1.1 要求 ≥2.2.5），而 Flask 2.3+ 兼容 Werkzeug 3.x
  → **werkzeug 反而无需处理**。
- `.gitignore` 已含 `.venv/`（无前导斜杠，匹配任意层级），不入库。
- 验收：`import app` 成功（含索引初始化）。
