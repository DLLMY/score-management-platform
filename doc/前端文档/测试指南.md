# 前端测试指南

## 概述

本项目使用 Jest 和 React Testing Library 进行前端测试。测试覆盖了组件、工具函数、API服务等方面。

## 安装依赖

测试依赖已包含在 `package.json` 中：

```bash
npm install
```

## 运行测试

### 运行所有测试

```bash
npm test
```

### 运行特定测试文件

```bash
# 运行组件测试
npm test -- Button.test.jsx

# 运行API测试
npm test -- api.test.js

# 运行验证函数测试
npm test -- validation.test.js
```

### 交互模式

```bash
npm test -- --watch
```

在交互模式中可以：
- 按 `a` 运行所有测试
- 按 `f` 只运行失败的测试
- 按 `q` 退出
- 按 `t` 按测试名称过滤

### 生成覆盖率报告

```bash
npm test -- --coverage
```

生成HTML覆盖率报告在 `coverage/` 目录。

## 测试示例

### 组件测试

```jsx
import { render, screen, fireEvent } from '@testing-library/react';
import Button from '../Button';

describe('Button', () => {
  it('应该正确渲染按钮文本', () => {
    render(<Button>点击我</Button>);
    expect(screen.getByText('点击我')).toBeInTheDocument();
  });

  it('应该处理点击事件', () => {
    const onClick = jest.fn();
    render(<Button onClick={onClick}>点击我</Button>);
    fireEvent.click(screen.getByText('点击我'));
    expect(onClick).toHaveBeenCalledTimes(1);
  });

  it('应该正确应用禁用状态', () => {
    render(<Button disabled>禁用按钮</Button>);
    expect(screen.getByText('禁用按钮')).toBeDisabled();
  });
});
```

### Hook测试

```jsx
import { renderHook, act } from '@testing-library/react-hooks';
import { useCounter } from '../useCounter';

describe('useCounter', () => {
  it('应该正确初始化', () => {
    const { result } = renderHook(() => useCounter());
    expect(result.current.count).toBe(0);
  });

  it('应该正确递增', () => {
    const { result } = renderHook(() => useCounter());
    
    act(() => {
      result.current.increment();
    });
    
    expect(result.current.count).toBe(1);
  });
});
```

### API服务测试

```jsx
global.fetch = jest.fn();

describe('API Service', () => {
  beforeEach(() => {
    fetch.mockClear();
  });

  it('应该正确处理API响应', async () => {
    const mockData = { success: true, data: [] };
    fetch.mockResolvedValueOnce({
      ok: true,
      json: () => Promise.resolve(mockData)
    });

    const response = await fetch('/api/users');
    const data = await response.json();
    
    expect(data.success).toBe(true);
  });

  it('应该处理网络错误', async () => {
    fetch.mockRejectedValueOnce(new Error('Network error'));
    
    await expect(fetch('/api/users')).rejects.toThrow('Network error');
  });
});
```

## 最佳实践

### 1. 测试命名

```jsx
describe('ComponentName', () => {
  describe('when user does X', () => {
    it('should do Y', () => {
      // 测试逻辑
    });
  });
});
```

### 2. 测试独立性

每个测试应该是独立的，不要依赖其他测试的执行顺序。

```jsx
// ✗ 不好：依赖执行顺序
it('步骤1', () => {
  // 设置状态
});
it('步骤2', () => {
  // 使用步骤1设置的状态
});

// ✓ 好：每个测试独立
describe('用户操作', () => {
  beforeEach(() => {
    // 每个测试前重置状态
    setupTestState();
  });
  
  it('应该执行操作A', () => {
    // 独立测试
  });
  
  it('应该执行操作B', () => {
    // 独立测试
  });
});
```

### 3. Mock外部依赖

```jsx
// Mock API调用
global.fetch = jest.fn();

// Mock模块
jest.mock('../utils/api', () => ({
  getUsers: jest.fn()
}));

// Mock定时器
jest.useFakeTimers();
```

### 4. 优先使用用户事件

```jsx
// ✗ 不好
fireEvent.click(button);

// ✓ 好
userEvent.click(button);
```

## 持续集成

在 CI/CD 中运行测试：

```yaml
# .github/workflows/test.yml
name: Frontend Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Use Node.js
        uses: actions/setup-node@v2
        with:
          node-version: '16'
      - name: Install dependencies
        run: npm ci
      - name: Run tests
        run: npm test -- --coverage --ci
      - name: Upload coverage
        uses: codecov/codecov-action@v2
```

## 常见问题

### Q: 如何调试失败的测试？

A: 使用 `--watch` 模式，然后按 `p` 输入测试名称过滤，按 `d` 进入调试模式。

### Q: 如何跳过某些测试？

A: 使用 `test.skip()` 或 `describe.skip()`：

```jsx
test.skip('这个测试将被跳过', () => {
  // ...
});
```

### Q: 如何只运行某些测试？

A: 使用 `test.only()` 或 `describe.only()`：

```jsx
test.only('只运行这个测试', () => {
  // ...
});
```

### Q: 如何测试异步代码？

A: 使用 `async/await` 和 `findBy` 查询：

```jsx
it('应该加载用户数据', async () => {
  render(<UserList />);
  
  // 等待数据加载
  const user = await screen.findByText('张三');
  expect(user).toBeInTheDocument();
});
```
