## 命名规范

### 文件命名

1. **组件文件**：使用PascalCase命名法
   - 正确：`Button.tsx`, `UserList.tsx`
   - 错误：`button.tsx`, `userList.tsx`

2. **样式文件**：使用kebab-case命名法
   - 正确：`button-style.ts`, `user-list.ts`
   - 错误：`buttonStyle.ts`, `UserList.ts`

3. **工具函数文件**：使用kebab-case命名法
   - 正确：`date-utils.ts`, `validation.ts`
   - 错误：`dateUtils.ts`, `Validation.ts`

### 变量命名

1. **组件变量**：使用PascalCase
   ```typescript
   const MyComponent: React.FC = () => { ... }
   ```

2. **普通变量**：使用camelCase
   ```typescript
   const userName = '张三';
   const isLoading = false;
   ```

3. **常量**：使用UPPER_SNAKE_CASE
   ```typescript
   const MAX_RETRY_COUNT = 3;
   const API_BASE_URL = '/api';
   ```

4. **接口/类型**：使用PascalCase，可添加I前缀或使用后缀
   ```typescript
   interface UserInfo { ... }
   type UserRole = 'admin' | 'teacher' | 'student';
   ```

### CSS类名命名

使用BEM命名规范：

```css
/* 块 */
.card { ... }

/* 元素 */
.card__title { ... }
.card__content { ... }

/* 修饰符 */
.card--primary { ... }
.card__title--large { ... }
```

## 代码风格规范

### TypeScript规范

1. **类型定义**
   - 必须为组件Props定义接口或类型
   - 必须为API响应定义类型
   - 避免使用`any`类型

   ```typescript
   // 正确
   interface ButtonProps {
     variant?: 'primary' | 'secondary';
     size?: 'sm' | 'md' | 'lg';
     children: React.ReactNode;
   }

   // 错误
   const Button = (props: any) => { ... }
   ```

2. **函数组件**
   - 优先使用箭头函数
   - 优先使用FC类型或直接声明

   ```typescript
   // 推荐
   const Button: React.FC<ButtonProps> = ({ variant, children }) => {
     return <button className={variant}>{children}</button>;
   };

   // 也可接受
   function Button({ variant, children }: ButtonProps) {
     return <button className={variant}>{children}</button>;
   }
   ```

3. **导入顺序**
   ```typescript
   // 1. React相关
   import React, { useState, useEffect } from 'react';

   // 2. 第三方库
   import { useNavigate } from 'react-router-dom';
   import { useQuery } from '@tanstack/react-query';

   // 3. 项目内部 - 组件
   import { Button, Card } from '@/components';

   // 4. 项目内部 - 其他
   import { useAuth } from '@/hooks';
   import { api } from '@/services';

   // 5. 类型定义
   import type { User } from '@/types';

   // 6. 样式
   import './Button.css';
   ```

### React规范

1. **组件拆分**
   - 单个组件不超过200行
   - 复杂逻辑抽离为自定义Hook
   - 复用逻辑抽离为公共组件

2. **状态管理**
   - 组件内部状态使用useState
   - 跨组件状态使用Context
   - 服务端状态使用React Query

3. **副作用处理**
   - 使用useEffect时必须包含依赖数组
   - 清理副作用（如定时器、订阅）

   ```typescript
   useEffect(() => {
     const timer = setInterval(() => {
       setTime(Date.now());
     }, 1000);

     return () => clearInterval(timer);
   }, []);
   ```

4. **条件渲染**
   - 使用短路运算符或三元运算符
   - 避免在JSX中使用复杂的条件语句

   ```typescript
   // 推荐
   {isLoading && <Spinner />}
   {user ? <UserProfile user={user} /> : <LoginPrompt />}

   // 避免
   {(() => {
     if (isLoading) return <Spinner />;
     if (!user) return <LoginPrompt />;
     return <UserProfile user={user} />;
   })()}
   ```

### CSS规范

1. **样式方案**
   - 优先使用Tailwind CSS
   - 复杂样式使用CSS Modules或CSS-in-JS
   - 避免内联样式（除动态计算样式外）

2. **响应式设计**
   ```css
   /* 移动优先 */
   .container {
     padding: 1rem;
   }

   /* 平板 */
   @media (min-width: 768px) {
     .container {
       padding: 2rem;
     }
   }

   /* 桌面 */
   @media (min-width: 1024px) {
     .container {
       padding: 3rem;
     }
   }
   ```

3. **颜色使用**
   - 通过CSS变量定义主题色
   - 避免硬编码颜色值

   ```css
   :root {
     --primary-color: #1890ff;
     --text-color: #333;
   }

   .button {
     background-color: var(--primary-color);
     color: var(--text-color);
   }
   ```

## API调用规范

### 服务层封装

```typescript
// services/api.ts
const api = {
  get: async <T>(url: string, params?: object): Promise<T> => {
    const response = await fetch(`${BASE_URL}${url}?${new URLSearchParams(params)}`);
    if (!response.ok) throw new Error('API Error');
    return response.json();
  },

  post: async <T>(url: string, data?: object): Promise<T> => {
    const response = await fetch(`${BASE_URL}${url}`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(data),
    });
    if (!response.ok) throw new Error('API Error');
    return response.json();
  },
};
```

### 错误处理

```typescript
try {
  const user = await api.get<User>('/users/1');
} catch (error) {
  if (error instanceof NetworkError) {
    showToast('网络连接失败');
  } else if (error instanceof AuthError) {
    navigate('/login');
  } else {
    showToast('未知错误');
  }
}
```

## 测试规范

### 单元测试

```typescript
// components/__tests__/Button.test.tsx
import { render, screen, fireEvent } from '@testing-library/react';
import { Button } from '../Button';

describe('Button', () => {
  it('renders correctly', () => {
    render(<Button>Click me</Button>);
    expect(screen.getByText('Click me')).toBeInTheDocument();
  });

  it('handles click event', () => {
    const onClick = jest.fn();
    render(<Button onClick={onClick}>Click me</Button>);
    fireEvent.click(screen.getByText('Click me'));
    expect(onClick).toHaveBeenCalled();
  });
});
```

## Git提交规范

### 提交信息格式

```

<body>

<footer>
```

### Type类型

- `feat`: 新功能
- `fix`: 修复bug
- `docs`: 文档更新
- `style`: 代码格式（不影响功能）
- `refactor`: 重构
- `perf`: 性能优化
- `test`: 测试
- `chore`: 构建或辅助工具

## 可访问性规范 (A11Y)

1. **语义化HTML**
   ```html
   <button>而不是<div onClick>
   <nav>用于导航区域
   <main>用于主要内容
   ```

2. **ARIA属性**
   ```html
   <button aria-label="关闭" onClick={handleClose}>
   <input aria-invalid={hasError} />
   ```

3. **键盘导航**
   - 确保所有交互可通过键盘完成
   - 使用合理的tab顺序

4. **颜色对比度**
   - 文本与背景对比度至少4.5:1
   - 大文本对比度至少3:1
