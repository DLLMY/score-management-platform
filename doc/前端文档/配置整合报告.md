## 二、统一配置模块结构

### 2.1 模块位置

`src/config/index.ts` - 前端统一配置管理模块

### 2.2 类型接口定义

```typescript
// 主要接口
interface ApiConfig          // API配置
interface MqttConfig         // MQTT配置
interface WebSocketConfig    // WebSocket配置
interface CacheConfig        // 缓存配置
interface DevToolsConfig     // 开发工具配置
interface SecurityConfig     // 安全配置
interface PerformanceConfig  // 性能监控配置
interface Config             // 完整配置
```

### 2.3 导出函数

| 函数名 | 功能说明 |
|-------|---------|
| `createConfig()` | 创建配置对象 |
| `getConfig()` | 获取配置实例 |
| `getMqttUrl()` | 获取MQTT连接URL |
| `getWebSocketUrl()` | 获取WebSocket连接URL |
| `getApiUrl()` | 获取API基础URL |
| `getCacheTtlByUrl()` | 根据URL获取缓存TTL |
| `validateConfig()` | 验证配置完整性 |
| `getConfigSummary()` | 获取配置摘要 |
| `logConfigSummary()` | 打印配置摘要(开发环境) |

## 六、使用方式

### 6.1 导入配置

```typescript
// 方式1: 导入配置实例
import { config } from './config';

// 使用配置
const apiUrl = config.api.fullUrl;
const mqttUrl = config.mqtt.broker;

// 方式2: 使用辅助函数
import { getApiUrl, getMqttUrl, getWebSocketUrl } from './config';

const apiUrl = getApiUrl();
const mqttUrl = getMqttUrl();
const wsUrl = getWebSocketUrl();
```

### 6.2 验证配置

```bash
# 运行配置验证脚本
node scripts/verify_config.js
```

### 6.3 查看配置摘要

配置模块会在开发环境启动时自动打印配置摘要到控制台。
