# 安全审计日志指南

## 概述

本项目实现了全面的安全审计日志系统，记录所有关键操作和安全事件，便于事后追溯和合规审计。

## 特性

- ✅ **多层次日志记录**: 文件日志 + 数据库日志
- ✅ **安全事件分类**: 认证、授权、数据操作、设备控制等
- ✅ **实时监控**: 暴力破解检测、频率限制检查
- ✅ **严重程度分级**: debug, info, warning, critical
- ✅ **操作追溯**: 记录操作人、IP、时间、变更前后数据

## 日志文件

### 日志位置
```
backend/logs/
├── app.log              # 应用运行日志
├── error.log            # 错误日志
├── security_audit.log   # 安全审计日志
└── security_critical.log # 高危操作日志
```

### 日志格式

```json
{
    "timestamp": "2024-01-15T10:30:00",
    "event_type": "login_success",
    "description": "用户认证成功: admin",
    "username": "admin",
    "success": true,
    "ip_address": "192.168.1.100"
}
```

## 使用方法

### 1. 基础使用

```python
from utils.security_audit import security_logger, SecurityEventType

# 记录安全事件
security_logger.log_event(
    SecurityEventType.DATA_EXPORT,
    "导出用户数据",
    username="admin",
    record_count=100
)
```

### 2. 便捷函数

```python
from utils.security_audit import (
    log_login,
    log_device_unlock,
    log_data_access,
    log_system_change,
    log_security_alert,
    log_permission_denied
)

# 记录登录
log_login("admin", success=True)

# 记录设备开锁
log_device_unlock("ESP32_001", "A", success=True)

# 记录数据访问
log_data_access("user", "export", record_id=123)

# 记录配置变更
log_system_change("mqtt_broker", "old_value", "new_value")

# 记录安全告警
log_security_alert("sql_injection", "检测到SQL注入攻击", ip_address="192.168.1.100")

# 记录权限拒绝
log_permission_denied("/api/admin/users", "权限不足")
```

### 3. 使用装饰器

```python
from utils.security_audit import audit_log, security_event

# 记录函数执行
@audit_log('function_execution')
def sensitive_operation(data):
    # 操作逻辑
    pass

# 记录安全事件
@security_event('sensitive_data_access', severity='warning')
def get_user_sensitive_info(user_id):
    # 获取敏感信息
    pass
```

### 4. 实时监控

```python
from utils.security_audit import security_monitor, security_logger, SecurityEventType

# 检查暴力破解
if security_monitor.check_brute_force("192.168.1.100", max_attempts=5):
    # 检测到暴力破解
    pass

# 记录失败尝试
security_monitor.record_failed_attempt("192.168.1.100")

# 检查请求频率
if security_monitor.check_rate_limit("192.168.1.100", max_requests=100):
    # 请求过于频繁
    pass
```

## 安全事件类型

## 集成到现有代码

### 在Flask应用中使用

```python
from flask import Flask
from utils.security_audit import register_security_middleware, log_login

app = Flask(__name__)

# 注册安全中间件
register_security_middleware(app)

# 在登录路由中使用
@app.route('/api/auth/login', methods=['POST'])
def login():
    # 登录逻辑
    if login_success:
        log_login(username, success=True)
        return {'success': True}
    else:
        log_login(username, success=False, reason='密码错误')
        return {'success': False}
```

### 在设备控制中使用

```python
from utils.security_audit import log_device_unlock

@app.route('/api/devices/<id>/control', methods=['POST'])
def device_control(id):
    action = request.json.get('action')
    
    if action == 'unlock_a':

    elif action == 'unlock_b':
        success = send_unlock_command(id, 'B')
        log_device_unlock(id, 'B', success)
```

## 审计日志分析

### 查询最近的安全事件

```python
from models import OperationLog
from datetime import datetime, timedelta

# 最近24小时的安全事件
recent_events = OperationLog.query.filter(
    OperationLog.operation_type.like('security%')
).filter(
    OperationLog.created_at >= datetime.now() - timedelta(days=1)
).all()

for event in recent_events:
    print(f"{event.created_at}: {event.description}")
```

### 统计登录失败次数

```python
# 按IP统计失败登录
failed_logins = OperationLog.query.filter(
    OperationLog.operation_type == 'login_failed'
).filter(
    OperationLog.created_at >= datetime.now() - timedelta(hours=1)
).all()

ip_counts = {}
for login in failed_logins:
    ip = login.ip_address
    ip_counts[ip] = ip_counts.get(ip, 0) + 1

# 找出可疑IP
suspicious_ips = [ip for ip, count in ip_counts.items() if count >= 5]
```

### 审计数据导出

```python
# 查询所有数据导出操作
exports = OperationLog.query.filter(
    OperationLog.operation_type == 'data_export'
).order_by(OperationLog.created_at.desc()).limit(100).all()

for export in exports:
    print(f"{export.created_at}: {export.operator} 导出了 {export.description}")
```

## 合规建议

### 1. 日志保留策略

- **普通日志**: 保留90天
- **安全日志**: 保留1年
- **高危操作日志**: 保留3年
- **定期归档**: 归档到冷存储

### 2. 日志保护

```python
# 日志文件权限设置 (Linux)
os.chmod('logs/security_audit.log', 0o600)  # 仅管理员可读写
os.chmod('logs/security_critical.log', 0o600)
```

### 3. 定期审计

```bash
# 统计最近一周的安全事件
grep "$(date -d '7 days ago' +%Y-%m-%d)" logs/security_audit.log | wc -l

# 查看登录失败次数
grep "login_failed" logs/security_audit.log | grep "$(date +%Y-%m-%d)" | wc -l
```

## 告警规则建议

### 高风险告警

1. **连续登录失败**: 5分钟内超过3次失败
2. **异常访问模式**: 非工作时间大量访问
3. **敏感数据导出**: 单次导出超过1000条记录
4. **权限变更**: 非管理员账户权限提升
5. **设备异常**: 短时间内设备频繁重启

### 中风险告警

1. **频繁访问**: 单IP每分钟超过100次请求
2. **数据批量删除**: 单次删除超过10条记录
3. **配置变更**: 系统关键配置修改
4. **新设备接入**: 未登记的设备接入

## 常见问题

### Q: 如何关闭安全日志？

```python
# 在配置中禁用
app.config['ENABLE_SECURITY_AUDIT'] = False
```

### Q: 日志文件太大怎么办？

A: 已配置日志轮转，单文件最大20MB，保留20个备份。

### Q: 如何导出审计报告？

```python
from datetime import datetime
import json

# 导出指定时间范围的审计日志
logs = OperationLog.query.filter(
    OperationLog.created_at >= start_date,
    OperationLog.created_at <= end_date
).all()

report = [log.to_dict() for log in logs]
with open('audit_report.json', 'w') as f:
    json.dump(report, f, ensure_ascii=False, indent=2)
```
