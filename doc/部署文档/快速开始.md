# 一键部署快速指南

## 🚀 5分钟快速部署

### 方法1：使用启动器（推荐）

1. **双击运行** `启动器.bat`
2. **选择** `[1] 一键部署`
3. **等待完成** 自动完成所有步骤
4. **访问系统** http://localhost:3000

### 方法2：直接运行一键部署

```bash
# 批处理版本
.\一键部署.bat

# 或Python版本（更好体验）
py .\一键部署.py
```

## 📋 一键部署包含的步骤

```
✅ 步骤1: 检查系统环境 (Python, Node.js, npm)
✅ 步骤2: 安装后端依赖 (Flask, SQLAlchemy等)
✅ 步骤3: 安装前端依赖 (React, Tailwind等)
✅ 步骤4: 创建配置文件 (.env)
✅ 步骤5: 初始化数据库 (SQLite)
✅ 步骤6: 清理端口占用 (3000, 5000, 4040)
✅ 步骤7: 启动后端服务 (端口5000)
✅ 步骤8: 启动前端服务 (端口3000)
```

## ⏱️ 预计时间

- **首次部署**: 5-10分钟（取决于网络速度）
- **后续启动**: 30秒-1分钟

## 🔧 常见问题

### Q1: 提示"Python未安装"
**解决方案**:
1. 下载安装 Python 3.10+ 
2. 安装时勾选 "Add Python to PATH"
3. 重启命令行窗口

### Q2: 提示"Node.js未安装"
**解决方案**:
1. 下载安装 Node.js 16+
2. 安装时勾选 "Add to PATH"
3. 重启命令行窗口

### Q3: 端口被占用
**解决方案**:
```bash
# 运行停止脚本
.\stop.bat

# 或手动清理
netstat -ano | findstr :5000
taskkill /F /PID <进程ID>
```

### Q4: 依赖安装失败
**解决方案**:
```bash
# 后端依赖
cd ..\backend
pip install -r requirements.txt

# 前端依赖
cd ..\frontend
npm cache clean --force
npm install
```

### Q5: 服务启动失败
**解决方案**:
1. 检查后端窗口和前端窗口的错误信息
2. 确认端口未被占用
3. 确认依赖已正确安装
