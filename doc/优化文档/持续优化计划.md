避免key冲突，提升系统稳定性。

#### O007: 前端缓存预热错误处理优化

| 项目 | 内容 |
|------|------|
| **ID** | O007 |
| **标题** | 缓存预热401错误被错误标记为成功 |
| **严重程度** | P1 |
| **状态** | ✅ 已完成 |
| **关联文件** | `frontend/src/services/cacheWarmupService.ts` |

**问题描述:**
需要登录的接口在未登录时返回401，但缓存预热服务仍标记为"预热成功"。

**优化方案:**
```typescript
private async fetchEndpoint(endpoint: CacheWarmupConfig['endpoints'][0]): Promise<void> {
  try {
    await request(endpoint.url, { skipCache: false });
    console.debug(`[CacheWarmup] 预热成功: ${endpoint.key}`);
  } catch (error) {
    const apiError = error as { status?: number };
    if (apiError.status === 401) {
      console.debug(`[CacheWarmup] 跳过需要登录的接口: ${endpoint.key}`);
    } else {
      console.debug(`[CacheWarmup] 预热失败: ${endpoint.key}`, error);
    }
  }
}
```

**预期效果:**
日志准确反映预热状态，便于问题排查。
