# PhoneBox 远程通知测试工具

用于测试远程通知功能的独立网页应用，支持全屏弹窗、语音播报、音量控制等功能。

## 📁 目录结构

```
remote-notify-test-tool/
├── index.html    # 主页面
├── style.css     # 样式文件
├── app.js        # 核心逻辑
└── README.md     # 说明文档
```

## 🚀 快速开始

### 方法一：直接打开

1. 双击 `index.html` 文件在浏览器中打开
2. 配置MQTT连接信息（默认已配置好测试服务器）
3. 点击「连接」按钮连接MQTT服务器
4. 填写通知内容，点击「发送通知」测试

### 方法二：本地服务器（推荐）

```bash
# 使用Python启动简单HTTP服务器
cd remote-notify-test-tool
python -m http.server 8080

# 然后在浏览器访问 http://localhost:8080
```

| 功能 | 说明 |

| 📤 发送通知 | 自定义通知内容、音量、显示时间 |

| 📺 全屏弹窗 | 支持远程显示全屏置顶弹窗 |
| 🎚️ 音量控制 | 远程调节接收端系统音量 |
| ⚡ 快捷预设 | 提供常用通知模板，一键发送 |
| 📊 状态监控 | 实时显示连接状态和发送统计 |

## 📋 使用说明

### 1. 配置连接

- **服务器地址**: `nc5233fc.ala.cn-hangzhou.emqxsl.cn`
- **端口**: `8084` (WebSocket)
- **SSL**: 开启
- **用户名**: `phoneboxtest`

### 2. 发送通知

1. 在「发送通知」区域填写：
   - **通知内容**: 要显示和播报的文本
   - **音量**: 0.0 ~ 1.0 (0% ~ 100%)
   - **显示时间**: 弹窗自动关闭时间（3-60秒）
   - **语音播报**: 是否启用语音
   - **全屏弹窗**: 是否显示弹窗

2. 点击「发送通知」或使用快捷预设

### 3. 快捷预设

| 预设 | 用途 |
|------|------|
| 🚨 紧急通知 | 高音量、长时间显示的紧急消息 |
| 📅 会议提醒 | 会议相关通知 |
| 🏫 上课提醒 | 课堂相关通知 |
| ☕ 休息提醒 | 休息时间通知 |
| ⚠️ 安全警告 | 安全相关警告 |
| ✅ 操作成功 | 操作成功提示 |

## 🧪 测试流程

1. **启动接收端**: 在目标电脑上运行接收端程序
   ```bash
   cd ../remote_notify
   python mqtt_listener.py
   ```

2. **启动测试工具**: 在浏览器中打开本工具

3. **连接MQTT**: 点击「连接」按钮

4. **发送测试**: 点击「发送测试消息」验证连接

5. **发送通知**: 填写内容并发送，接收端会显示弹窗和语音播报
