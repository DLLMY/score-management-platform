### 1.2 技术栈

**后端**:
- 框架: Flask + Flask-RESTX
- ORM: SQLAlchemy
- 认证: JWT + CSRF
- 数据库: SQLite (FTS5 全文搜索)
- 缓存: Redis
- 消息队列: Celery
- NLP: BERT + TextCNN + 轻量级分类器
- 实时通信: MQTT + WebSocket

**前端**:
- 框架: React 18 + TypeScript
- 路由: React Router v6
- 状态管理: Zustand
- 样式: Tailwind CSS
- 图表: Recharts
- 图标: Lucide React

### 1.3 架构特点

- ✅ **分层架构**: 路由层 → 服务层 → 数据层
- ✅ **模块化设计**: 按业务领域划分模块（学业、评分、设备、监控等）
- ✅ **微服务准备**: 具备 API 版本化、依赖注入容器
- ✅ **NLP 增强**: 自然语言解析支持多模型（BERT/TextCNN/规则引擎）
- ✅ **实时通信**: MQTT + WebSocket 双通道
