# ESP32手机管理箱开发设计指南 (DX-NF01版)

## 1. 系统概述

本项目是一个基于ESP32的双箱手机管理系统，支持：
- A箱：班主任远程控制开锁（MQTT）
- B箱：学生刷卡验证（积分≥60分）
- 网页配网功能
- 门状态检测
- OLED显示与LED/蜂鸣器提示

## 2. 硬件选型

### 2.1 核心模块
| 模块 | 型号 | 功能 |
|------|------|------|
| 主控 | ESP32 DevKit V1 | 系统核心控制 |
| RFID | DX-NF01（国产13.56MHz） | 学生卡识别 |
| 继电器 | 双路光耦隔离 | 电磁锁控制 |
| 显示 | SSD1306 128×64 I2C | 状态显示 |
| 提示 | 红/绿LED + 有源蜂鸣器 | 声光提示 |
| 电源 | 12V/2A适配器 + LM2596 | 供电系统 |

### 2.2 引脚分配
| 引脚 | 外设 | 方向 | 功能 |
|------|------|------|------|
| GPIO5 | 继电器A | OUT | 开A箱（高电平触发） |
| GPIO2 | 继电器B | OUT | 开B箱（高电平触发） |
| GPIO16 | DX-NF01 TX | UART2_RX | 模块TX -> ESP RX |
| GPIO17 | DX-NF01 RX | UART2_TX | 模块RX <- ESP TX |
| GPIO25 | 红LED | OUT | 低电平亮 |
| GPIO26 | 绿LED | OUT | 低电平亮 |
| GPIO27 | 蜂鸣器 | OUT | 低电平触发响 |
| GPIO32 | 门A开关 | IN_PULLUP | LOW=门闭 |
| GPIO33 | 门B开关 | IN_PULLUP | LOW=门闭 |
| GPIO15 | 配网按键 | IN_PULLUP | 长按3秒进入AP模式 |
| GPIO23 | RFID复位 | OUT | 模块复位信号 |

> **说明：** OLED使用硬件I2C（U8G2库自动管理SDA/SCL），默认引脚为GPIO21(SDA)和GPIO22(SCL)。

### 3.1 模块划分

## 4. 通信协议

### 4.1 DX-NF01 AT指令协议

DX-NF01模块使用标准AT指令进行通信，主要指令如下：

| 指令 | 功能 | 响应示例 |
|------|------|----------|
| AT | 测试指令 | OK |
| AT+VERSION | 查询版本 | VERSION:xxx |
| AT+RESET | 复位模块 | OK |
| AT+UID | 读取卡片UID | UID:3A76B29F |
| AT+TYPE | 读取卡片类型 | TYPE:MIFARE_CLASSIC_1K |
| AT+READ=<type><address> | 读取扇区数据 | DATA:xxxxxxxx... |
| AT+WRITE=<type><address><data> | 写入扇区数据 | OK/ERROR |

**工作流程：**
1. 初始化时发送 `AT` 和 `AT+RESET`
2. 循环发送 `AT+UID` 查询是否有卡片
3. 解析响应中的 `UID:` 字段获取卡号

### 4.2 MQTT主题
| 主题 | 方向 | 说明 |
|------|------|------|
| phonebox/query | ESP→Server | B箱刷卡查询 |
| phonebox/unlock/A | Server→ESP | 开A箱指令 |
| phonebox/unlock/B | Server→ESP | 开B箱指令 |
| phonebox/status | ESP→Server | 门状态上报 |
| phonebox/log | ESP→Server | 操作日志 |
| phonebox/heartbeat | ESP→Server | 心跳包（每10秒） |
| phonebox/ota | Server→ESP | OTA升级指令 |
| phonebox/ota/status | ESP→Server | OTA升级状态上报 |

### 4.3 消息格式
- B箱刷卡查询：
```json
{
  "box_id": "B",
  "card_id": "3A76B29F",
  "timestamp": 1650000000,
  "type": "query"
}
```

- 开锁回复：
```json
{
  "result": "true",  // "true" 或 "false"
  "reason": "score_ok",
  "current_score": 85
}
```

- 门状态上报：
```json
{
  "box_id": "A",
  "status": "closed",
  "timestamp": 1650000000
}
```

- 心跳包（每10秒发送）：

- OTA升级指令（下发）：

- OTA升级状态上报：
```json

  "from_version": "2.5",
```

## 5. 关键技术点

### 5.1 EEPROM存储
使用ESP32内置EEPROM存储配置，地址0开始，大小512字节。

### 5.2 DX-NF01 RFID模块
- 波特率：默认9600（需根据模块实际配置调整）
- 工作频率：13.56MHz
- 支持协议：ISO14443A/B、ISO15693（MIFARE Classic 1K/4K等）
- 通信方式：AT指令（需主动发送查询命令）
- 模块资料：`../202507265960/DX-NF01资料包/`
- 视频教程：https://www.bilibili.com/video/BV1QEyVYVErH

### 5.3 看门狗机制
配网模式3分钟后自动重启。

## 6. 编译与烧录

1. 安装Arduino IDE (1.8.19+)
2. 安装ESP32开发板支持包
3. 安装依赖库（见libraries.md）
4. 选择开发板：`ESP32 Dev Module`
5. 选择正确的串口
6. 点击上传

详细测试方案见测试方案.md

## 8. 注意事项

1. 电磁锁必须单独使用12V电源，不得与ESP32共用5V
2. 所有模块必须共地
3. 继电器控制信号必须与模块规格匹配
4. RFID天线远离电磁干扰源
5. DX-NF01模块默认波特率为9600，需确保与配置一致
