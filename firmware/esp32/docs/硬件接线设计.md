## 4. 详细接线步骤

### 4.1 准备工作

1. 准备所有硬件组件
2. 准备杜邦线（公对公、公对母）
3. 准备端子排（可选，便于布线）
4. 准备热缩管或绝缘胶带（用于绝缘保护）

### 4.2 步骤1：连接DX-NF01 RFID模块

| 步骤 | 操作 |
| :--- | :--- |
| 1 | DX-NF01模块VCC → ESP32 5V |
| 2 | DX-NF01模块GND → ESP32 GND |
| 3 | DX-NF01模块TX → ESP32 GPIO17 |
| 4 | DX-NF01模块RX → ESP32 GPIO18 |
| 5 | DX-NF01模块RESET → ESP32 GPIO23（可选，可不接）|

### 4.3 步骤2：连接继电器模块

| 步骤 | 操作 |
| :--- | :--- |
| 1 | 继电器模块VCC → ESP32 5V |
| 2 | 继电器模块GND → ESP32 GND |
| 3 | 继电器模块IN1 → ESP32 GPIO4 |
| 4 | 继电器模块IN2 → ESP32 GPIO16 |

### 4.4 步骤3：连接OLED模块

| 步骤 | 操作 |
| :--- | :--- |
| 1 | OLED模块VCC → ESP32 5V |
| 2 | OLED模块GND → ESP32 GND |
| 3 | OLED模块SDA → ESP32 GPIO21 |
| 4 | OLED模块SCL → ESP32 GPIO22 |

### 4.5 步骤4：连接LED指示灯

| 步骤 | 操作 |
| :--- | :--- |
| 1 | 红色LED正极 → 限流电阻(220Ω) → ESP32 GPIO25 |
| 2 | 红色LED负极 → ESP32 GND |
| 3 | 绿色LED正极 → 限流电阻(220Ω) → ESP32 GPIO26 |
| 4 | 绿色LED负极 → ESP32 GND |

### 4.6 步骤5：连接蜂鸣器

| 步骤 | 操作 |
| :--- | :--- |
| 1 | 有源蜂鸣器VCC → ESP32 GPIO27 |
| 2 | 有源蜂鸣器GND → ESP32 GND |

### 4.7 步骤6：连接微动开关

| 步骤 | 操作 |
| :--- | :--- |
| 1 | 微动开关A公共端 → ESP32 GPIO32 |
| 2 | 微动开关A常开端 → ESP32 GND |
| 3 | 微动开关B公共端 → ESP32 GPIO33 |
| 4 | 微动开关B常开端 → ESP32 GND |

### 4.8 步骤7：连接电磁锁电源

| 步骤 | 操作 |
| :--- | :--- |
| 1 | 12V电源适配器正极 → 继电器COM1和COM2 |
| 2 | 12V电源适配器负极 → 所有GND |
| 3 | 继电器NO1 → 电磁锁A正极 |
| 4 | 继电器NO2 → 电磁锁B正极 |
| 5 | 电磁锁A负极 → GND |
| 6 | 电磁锁B负极 → GND |

### 4.9 步骤8：连接配置按键

| 步骤 | 操作 |
| :--- | :--- |
| 1 | 配置按键一端 → ESP32 GPIO15 |
| 2 | 配置按键另一端 → ESP32 GND |

## 6. 电源方案

### 6.1 电源分配

```
12V/2A电源适配器
    │
    ├── 继电器模块（控制电磁锁电源路径）
    │       │
    │       └── 12V → 电磁锁（通过继电器NO触点）
    │
    └── LM2596降压模块（12V → 5V）
            │
            └── ESP32 VIN引脚
                    │
                    ├── 5V输出 → DX-NF01、OLED、继电器逻辑端
                    │
                    └── 3.3V（内部转换）→ ESP32内部电路
```

### 6.2 电源注意事项

1. **DX-NF01模块电源**：支持3.3V/5V，建议使用5V供电更稳定
2. **共地要求**：所有模块必须共地，否则可能产生干扰
3. **电流容量**：建议使用2A以上电源适配器
4. **电源滤波**：在电磁锁两端并联续流二极管保护继电器

## 8. 安全注意事项

1. **断电操作**：接线时务必断开电源
2. **绝缘处理**：裸露的金属部分使用热缩管或绝缘胶带包裹
3. **电源极性**：注意电源正负极，避免反接
4. **电流保护**：继电器输出端建议使用保险丝
5. **散热处理**：降压模块和继电器工作时会发热，注意散热
6. **防静电**：操作ESP32和DX-NF01模块时注意防静电

## 9. 常见问题排查

| 现象 | 可能原因 | 排查方法 |
| :--- | :--- | :--- |
| DX-NF01无反应 | 串口接线错误 | 检查TX/RX引脚是否接反 |
| DX-NF01读卡失败 | 波特率不匹配 | 确认波特率设置为9600 |
| OLED不显示 | I2C接线错误 | 检查SDA/SCL引脚 |
| 继电器不吸合 | 控制信号未到达 | 测量GPIO输出电平 |
| 电磁锁不工作 | 电源未接通 | 测量继电器输出端电压 |
| LED不亮 | 限流电阻缺失 | 检查是否串联电阻 |
| 蜂鸣器不响 | 接线错误 | 检查GPIO27输出 |
| 设备不稳定 | 电源功率不足 | 使用更大功率电源适配器 |
