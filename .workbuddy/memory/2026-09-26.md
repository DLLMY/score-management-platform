### 关键坑（B17 新增）
- **eslint `import/first`**：`vi.mock(...)` 被 vitest 自动 hoist 到 import 之上，但 eslint 视其为「非 import 语句」——若 `import X from '../X'` 写在 `vi.mock` 之后会报 `import/first`。须把所有 `import`（含被测组件与 `usePermissionStore`）提到文件顶部 import 区（在 `const hoisted = vi.hoisted` 与 `vi.mock` 之前），mock 运行时仍生效。
