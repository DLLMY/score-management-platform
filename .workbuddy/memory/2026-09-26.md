### 关键坑（固化）
- **`ColumnType.render` 签名为 3 参 `(text, record, index)` 且可能 `undefined`**：直接 `col.render(...)` 报 TS2722(可能 undefined)+TS2554(期望3实参)。须 `col.render!(value, record, 0)`（非空断言 + 补 index 形参）。
- **`type=number` 的 input jsdom 会把非数字值清洗为空串**（`'abc'`→`''`），导致 onBlur 读不到非法值、NaN 分支无法经 DOM 触发 → 用 `Object.defineProperty(input, 'value', {configurable:true, value:'abc'})` 绕过 setter 直接置值。
- **测试文件相对路径深度**：`scoreEntry/__tests__/` 比源码深一级 → `src/types` 须 `../../../types`（3 个 `../`）；`ScoreItem` 来自 `../types`（1 个 `../`）。
- `getByText('')` 在空文本节点场景匹配多个（span/div/body）→ 改用 `container.querySelector('span')?.textContent` 精确断言。
