### 关键坑（固化）
- **lucide 图标按钮无文字 → 无障碍名 `''`**：`getByRole('button',{name:''})` 在「有关键字（清空 X 按钮出现）」时与 Save 图标按钮同名多匹配 → 改用容器查询 `container.querySelectorAll('button').find(b => b.querySelector('svg.lucide-save'))` 精确定位。
- **`handleChange` 合并语义**：AdvancedSearchFilter 各字段 onChange 携带此前所有字段（非仅当前字段）→ 断言须用 `expect.objectContaining({...})`，不能严格 `toHaveBeenCalledWith({...})`。
- **`objectContaining({ x: undefined })` 在 vitest 中对 undefined 值按「可选/可缺省」处理、与显式 `x:undefined` 不匹配** → 改用具体值（如 maxScore 设 '100' 断言 `maxScore:100`）验证 Number 转换分支。
- **loading 态搜索按钮文案变「搜索中...」**（非「搜索」）→ `getByRole('button',{name:'搜索中...'})`。
- **label 未与表单控件关联**（`<label>` 与 input 为兄弟节点，无 htmlFor/id）→ `getByLabelText` 失效；改用 `getByText('全部状态').closest('select')` 或容器 `querySelectorAll('input[type="date"|"number"]')` 定位。
- 组件仅依赖 `react`+`lucide-react`，**无需 mock 任何 barrel**，默认导出 `memo(...)` 用默认导入。
