## 关键技术修正（务必沉淀）
1. **MODULE_REF_NAMES（d2_split.py 新增）**：part 里对「模块级状态/函数」不局部 `from 主模块 import NAME`，而是 `import 主模块 as _mod` 后全量替换为 `_mod.NAME`（覆盖调用+属性/下标/赋值）。原因：测试直接 `patch("api.xxx.routes.NAME")` 或读写 `routes.NAME` 模块级对象，若 part 局部绑定则 patch 不命中、状态不同步。devices 的 `publish_mqtt`、nlp 的 `_get_ml_service/_get_parser/_train_lock/_train_seq/_train_tasks` 都靠它。重写用 `\bREF\b`→`_mod.REF`（单次 re.sub 不会二次扫描，安全）。
2. **re-point 前必须先 `git checkout HEAD -- 主文件` + 删 part 文件**再跑拆分器（拆分器只搬类，二次跑会因类已搬走而报错）。
3. **course_schedule 教训**：拆分器原本只搬 ClassDef，导致主壳 617>600。已扩展可搬 FunctionDef（GROUPING 里列函数名即可），把 import 辅助函数下沉 part2，主壳降到 311。
