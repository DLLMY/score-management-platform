- 方法：AST 脚本 `scripts/p2_5_print_to_logger.py`，规则——except 块→`log_warning(exception=<e>)`；`if __name__=="__main__"` 块→`log_debug`；显式 OVERRIDE 映射（非 except 告警/缓存调试行）；其余→`log_info`。零逻辑漂移。
- 踩坑（脚本已加固，下次复用直接可用）：
  1. ast 的 `col_offset/end_col_offset` 在本环境按 **UTF-8 字节**计（中文 3 字节/字），`len()` 按字符计 → 偏移错位吞掉下一行。修复：`off()` 把字节列经 `line.encode('utf-8')[:col].decode()` 转回字符列。
  2. `open(...,"w")` Windows 文本模式把 **LF** 文件翻成 CRLF（整文件 diff）。修复：二进制读写 `rb`/`wb` 精确保留行尾（CRLF/LF 各自不变）。
  3. 空 `print()` → `log_debug()` 会因 `message` 无默认值 `TypeError`；脚本置 `inner='""'`。
