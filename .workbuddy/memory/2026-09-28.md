## B35 · OptimizedImage 源码修复 + 纯展示 UI 组件补测（2026-09-28）

### OptimizedImage 懒加载死锁修复（源码）
- **根因**：旧实现 observer 绑在 `imageSrc` 就绪后才挂载的真实 `<img>`（imgRef），而 `imageSrc` 又由 `IntersectionObserver` 回调置值；
  守卫 `if (!lazy || !imgRef.current) return` 在 `imgRef.current` 为 null 时提前 return → 观察者永不创建 → `isInView` 恒 false → 真实 img 永不渲染。
  即「先有鸡还是先有蛋」死锁，懒加载分支（进入视口触发 / IO 未定义守卫）在生产中实际不可达。
- **修复**：新增 `containerRef` 绑到**始终挂载**的包裹 `<div>`，observer 改观察 `containerRef.current`（移除不再需要的 `imgRef`）。纯重构观察者挂载点，零逻辑变更。
- **测试补可达分支**：重写 `OptimizedImage.test.tsx`，新增「lazy + 可控 FiringIntersectionObserver 触发 isIntersecting → 渲染真实图片」与「无 IntersectionObserver → 守卫直接置 isInView=true」两个此前不可达分支（test-setup 默认 stub 的 observe 为空操作，故另设可控 mock）。
