### OptimizedImage 懒加载死锁修复（源码）
- **根因**：旧实现 observer 绑在 `imageSrc` 就绪后才挂载的真实 `<img>`（imgRef），而 `imageSrc` 又由 `IntersectionObserver` 回调置值；
  守卫 `if (!lazy || !imgRef.current) return` 在 `imgRef.current` 为 null 时提前 return → 观察者永不创建 → `isInView` 恒 false → 真实 img 永不渲染。
  即「先有鸡还是先有蛋」死锁，懒加载分支（进入视口触发 / IO 未定义守卫）在生产中实际不可达。
