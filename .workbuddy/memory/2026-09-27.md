### 仓库损坏恢复（B25 重大坑：packed-refs CRLF 污染）
- 症状：commit `b22fe97` 后 stderr `fatal: bad object refs/heads/main?` / `error: failed to perform geometric repack`；`git fsck` 报 `packed-refs line N: badRefName 'refs/heads/main?'` + `invalid sha1 pointer 0000000...`（refs/heads/main? 与 refs/remotes/origin/main? 各一条）。
- 根因：`.git/packed-refs` 被写成 **CRLF**（git 要求 LF），尾随 `\r` 被吞进 refname → `refs/heads/main\r` 变非法 refname（fsck 渲染成 `main?`）；外加两条**全零 SHA 墓碑垃圾行**（`refs/heads/main`/`refs/remotes/origin/main` 各一条重复全零记录）。
- 修复：字节视图确认 CRLF + 全零行 → Python `open(pr,'wb')` 写回**纯 LF** 干净 packed-refs（仅留两条有效 ref：`refs/heads/main`=b22fe97、`refs/remotes/origin/main`=9123783，先备份 packed-refs.bak）；`git fsck --no-dangling` 转 EXIT=0 零报错。
- ⚠️ **`git update-ref -d "refs/heads/main?"` 失败**：`?` 触发 Windows 文件名非法（Invalid argument），git 命令无法删非法 refname → 必须 Python 字节级重写（技能 `git-windows-shim-safe` 认可）。
- 推送核验：`git push origin main` → `9123783..b22fe97`；`git ls-remote --heads origin main` 返回 `b22fe97` == 本地 HEAD ✓（已清理 packed-refs.bak）。
