### 业务指标埋点（metrics_exporter + 4 服务）
- `metrics_exporter.py`：新增 7 个业务指标（ota_updates_total / ota_negotiations_total / mqtt_connection_state / mqtt_messages_total / score_devices_online / score_devices_total / redis_cache_ops_total）及安全 helper（try/except 包裹）。
- 埋点接线：firmware_service、mqtt_manager、heartbeat_service（set_device_counts）、ota_negotiation_service（negotiate() → record_ota_negotiation）。
- **关键坑（已修）**：这 4 个服务里把 `from app.metrics_exporter import ...` 放在模块顶层会触发与 `app` 包的**循环导入**——`import app.metrics_exporter` 先执行 `app/__init__.py`，它回引这些服务导致整个后端无法 import（compare_versions / create_firmware_version / MQTTManager 全部 ImportError）。
  - 修法：改为**同名模块级延迟包装函数**（运行时 app 已完整初始化，无环），调用点零改动。heartbeat_service 本来就是函数内局部导入，幸免。
  - 经验：backend 服务里禁止顶层 import `app.*`（会拉起 app 包），一律用函数内 lazy import 或同名延迟包装。
