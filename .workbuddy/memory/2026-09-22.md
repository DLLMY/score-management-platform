## 关键缺口（按优先级）
- **P0-a 占位密钥入库**：`.env.production`/`.env.development` **未被 gitignore**（仅真实 `.env` 被忽略），且内含字面 `FLASK_SECRET_KEY=CHANGE_ME_IN_PRODUCTION_...` / 同样 JWT 密钥。`validate_secret_keys` 只校验"非空"，占位值可过检 → 若误用即全仓公开签名密钥、可伪造 admin token。修复：这俩文件纳入 gitignore 或改名 `.example`；启动期追加"拒绝已知占位值"断言（纵深防御）。
- **P0-b WebSocket 生产入口断裂**：Dockerfile CMD `gunicorn --workers=4 --threads=2 backend.wsgi:application` 用**默认 sync worker**，而 `init_websocket`(`service_init.py:340`)用 `async_mode="threading"`；gunicorn sync worker 不处理 WS 升级 → 实时功能（设备状态/WS 通知）在容器化 prod **静默失效**。且 `run.py` 用 `socketio.run`（Werkzeug 开发服务器）才接好 WS，但与 gunicorn 互斥。修复：统一为 `gunicorn -k geventwebsocket.gunicorn.workers.GeventWebSocketWorker -w1 backend.wsgi:application` + `async_mode="gevent"`，或单独 WS 服务。
- **P0-c TLS/HTTPS 缺失 + 安全 cookie 互斥**：`nginx.conf` 仅 `listen 80`，无 443/SSL/80→443 跳转/HSTS；但 prod `SESSION_COOKIE_SECURE=True` → 纯 HTTP 下登录会话 cookie 写不进去，**登录功能在 prod 直接坏**。模板 `ENABLE_HTTPS=true` 是占位。修复：前端 nginx 或前置网关做 TLS（certbot/Let's Encrypt）。
- **P0-d 无版本化 DB 迁移**：`apps/backend/migrations/` 是 ~16 个一次性 `fix_*.py`（无 alembic.ini/versions/env.py/回滚），新装靠 `db.create_all()`(`db_init.py:33`)，存量靠手工脚本。多环境漂移/回滚无保障。修复：引入 Alembic（autogenerate + schema_version 表）或至少单一幂等迁移入口。
- **P1 真实部署未自动化**：deploy.yml 只 build+Release，`deploy-windows` 禁用，部署到服务器是占位；且**迁移步骤不在部署流程内**。
- **P1 日志不持久**：compose 只挂 `backend-data:/app/backend/instance`，`/app/backend/logs` 未挂卷 → 容器重建即丢日志，无集中采集。gunicorn access/error 也写此目录。
- **P1 限流器存储**：Flask-Limiter 默认**内存存储**，4 个 gunicorn worker 各自计数 → 跨 worker 限流失效/不均。需用 Redis 存储。
- **P1 依赖未锁定**：后端 `requirements.txt` 全用 `>=`（Flask>=2.0 等）+ 重型未固定（numpy/pandas/scipy/sklearn），Dockerfile `pip install -r` 非确定性。前端 `npm ci` 已锁定。建议 pip-tools/poetry 锁文件。
- **P1 备份**：`BACKUP_ENABLED` 默认 false（模板里 true），SQLite 单文件需定期+异地备份；compose 无备份工具。
- **P1 监控/告警**：`prometheus-client` 已依赖但**未暴露 `/metrics`**（grep 无 make_asgi_app/start_http_server；`/api/system/metrics` 是业务指标 API，需鉴权，非监控端点）→ 无 scrapeable 指标/告警。
- **P2 SQLite 并发天花板**：写并发受限（WAL+busy_timeout5000+pool20/40 已缓解），ESP32 设备心跳/积分写入突发下 `database is locked` 风险；建议 prod 评估 PostgreSQL。
- **P2 死配置**：`.env.production` 既有真实键 `RATE_LIMIT_PER_MINUTE=30` 又有未使用键 `RATE_LIMIT_DEFAULT=1000 per hour` 等 → 清理。
- **P2 前端 MQTT broker**：`apps/frontend/.env` 用 `broker.hivemq.com`(公共测试 broker) 而非记忆中的 EMQX Cloud，prod 需指向真实 broker。
- **P2 FLASK_ENV 弃用**：Flask 2.3+ 弃用 `FLASK_ENV`，应改用 `FLASK_DEBUG`；启动期 setdefault 多处。
- **P2 覆盖率闸门**：CI 未加 `--cov` 阈值门槛；无 E2E/soak 测试进 CI（仅手动 `run_performance_test.py`）。
